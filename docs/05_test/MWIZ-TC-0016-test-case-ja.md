## 2. 準備

- 単体：`tests/helpers/maps.ts` の `openMap(player, extra, floor)`（上り (0,9)、下り (9,0)、5F はボス (9,0)）と `dungeonState`。乱数を引かないことは、呼ぶと例外を投げる Rng（または空の `SequenceRng`）で確かめる。
- E2E：`?debug=1` で開き、`startAt('DUNGEON', …)` で 1F の下り階段の 1 マス手前（北向き、正面が下り階段）、下り階段の上、入口の上、何もないマスの上、などの状態を作る。歩くテストは `useSeed` で遭遇しないシードにする。
