## 2. 準備

- 単体：`tests/helpers/fixtures.ts` の所持品つきの状態（部位ごとに強さの違う個体、50 個の所持品、49 個の所持品）。入力は `deepFreeze` する。ゲーム API は `fake-storage.ts` と `SwappableRng`。
- E2E：`?debug=1` で開き、`startAt('INN', …)` で、ぶきに バトルアックス［R］（こうげき +10）、アクセに ソロモンのゆびわ［LG］（+30）を付け（v1.3：新しい範囲で出る値にした）、たては空き、所持品に ぶき 3 個（強いもの・弱いもの・同じ段階で補正値違い）を持つ状態から始める。ダンジョンからの確かめは `startAt('DUNGEON', …)`。
