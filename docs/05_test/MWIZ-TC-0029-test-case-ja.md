## 2. 準備

- 単体：`tests/helpers/fixtures.ts` の所持品つきの状態。ゲーム API は `fake-storage.ts`（古いデータ・壊れた個体を直接書いておく）と `SwappableRng`。`console.warn` は `vi.spyOn` で見る。
- E2E：`?debug=1` で開き、`startAt('INN', …)` で所持品 23 個（ショートソード［R］・部位がばらばらの個体）を持つ状態から始める。50 個・0 個の状態も同じ入口で作る。入れ替えの画面は `startAt('SWAP', …)`。
