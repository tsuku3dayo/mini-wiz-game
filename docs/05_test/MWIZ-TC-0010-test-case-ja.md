## 2. 準備

- 単体：`menu-model` に項目の一覧（有効・無効）と `initialIndex`・`trapFocus` を渡して、キーごとの次のカーソルを表で確かめる。
- E2E：`?debug=1` で開き、`__wiz.writeState` で宿屋（名前「ゆうしゃ」）・ダンジョン（MP 2）・戦闘の状態を作る（`startAt`）。
