# TC-0004 新しい版に更新する

- 対象：[US-0004](../02_requirements/MWIZ-US-0004-user-story-ja.md)（受け入れ条件 3 つ）
- 方法の分け方・置き場所の決まりは [TST-0001](MWIZ-TST-0001-test-strategy-ja.md)。

## 1. 確認の一覧

| 確認 ID | 条件 | 確かめること（期待する結果） | 方法 | 置き場所 |
| --- | --- | --- | --- | --- |
| TC-0004-01 | 1 | `__wiz.showUpdateBanner()` のあと、タイトル画面と宿屋の画面で `#update-banner` が見え、「新しい版があります」と `#update-button`（「更新」）が出る。帯は画面の上端に固定（`position: fixed`、`getBoundingClientRect().top` が安全領域の内側） | E2E | `e2e/pwa.spec.ts` |
| TC-0004-02 | 2 | 帯を出した状態で、ダンジョン・戦闘・入れ替え・ゲームクリアの画面と名前入力では `#update-banner` が見えない。宿屋 →「ダンジョンへ」で消え、1F の入口から宿屋へ戻るとまた出る | E2E | `e2e/pwa.spec.ts` |
| TC-0004-03 | 3 | 帯を出して 30 秒（偽の時計）たっても、ページが読み込み直されない（`framenavigated` が起きない）。プレイ中の状態とセーブ（`localStorage` の `mini-wiz-game-game`・`mini-wiz-game-save`）がそのまま | E2E | `e2e/pwa.spec.ts` |
| TC-0004-04 | 3 | 新しい版を公開したあと、iPhone 11 のホーム画面のアプリで宿屋の画面に帯が出て、「更新」を押すと新しい版に切り替わる。切り替わったあとも、プレイ中の状態（場所・HP・所持品）とセーブ（タイトルの「つづきから」の「{名前} Lv{n}」）が残っている。押すまでは切り替わらない | 手動 | 実機（iPhone 11） |

## 2. 準備

- E2E：`?debug=1` で開き、`__wiz.writeState`・`writeSave` で宿屋（または各画面）の状態とセーブを作ってから `__wiz.showUpdateBanner()` を呼ぶ（`e2e/helpers.ts` の `startAt`）。
- 手動：リリースの前の WS で、版を上げたものを `main` にマージして公開する（ホーム画面のアプリは `?debug=1` を使えない。TST-0001 §6）。

## 3. 手順（E2E）

| 確認 ID | 手順 |
| --- | --- |
| TC-0004-02 | 宿屋で帯を出す → 見えることを確かめる →「ダンジョンへ」→ 見えない → `writeState` で戦闘・入れ替え・クリアにしてそれぞれ見えない → 1F の入口の状態で「宿屋へ戻る」→ 見える |
| TC-0004-03 | `page.clock.install()` → 宿屋で帯を出す → `page.on('framenavigated')` を数える → `runFor(30000)` → 数が 0。保存の値を前後で比べる |

## 4. 手動の手順

| 確認 ID | 手順 | 期待する結果 |
| --- | --- | --- |
| TC-0004-04 | 前の版のホーム画面のアプリで遊び、宿屋でセーブしてから、ダンジョンを歩いてプレイ中の状態を作る → 新しい版を公開する → アプリを開き直す → ダンジョンにいるあいだ帯が出ないことを見る → 宿屋に戻る → 帯の「更新」を押す | ダンジョンでは帯が出ない。宿屋で「新しい版があります」と「更新」が出る。押すまで切り替わらない。押すと読み込み直して新しい版（タイトルの版の表記・変えた所）になり、宿屋の HP・所持品とセーブが残っている |
