## 1. 元の依頼（オーナーの文のまま）

```
1.かいひ：すばやさの値
2.回避：盾は回避アップに変更
　・攻撃の回避判定：防御側の「かいひ」 - 攻撃側の「すばやさ」 = 回避率
 　・例：防御側の「かいひ」：50 - 攻撃側の「すばやさ」30 = 20 → 回避：20%
　・ただし、どんなに差が開いても10%は攻撃があたる
3.スマホの場合のバトル画面のコマンドウィンドウ枠は無くす（ボタンは、併せて大きくする）
```

## 2. 確かめたこととオーナーの回答（2026-11-11）

| # | 確かめたこと | 回答 |
| --- | --- | --- |
| 1 | 「かいひ」の値 | **すばやさ（装備込み。ウィンドブーツの補正も入る）＋ たての補正**。例：すばやさ 5・たて +6 → かいひ 11 |
| 2 | 敵の「かいひ」（敵は たて を持たない） | **その敵のすばやさ** |
| 3 | ステータスの「かいひ」の行の見せ方 | **ほかの能力と同じく、補正があれば「 11 (+6)」**。装備画面の のうりょく は「 11 =   5 + 6」（基礎＝すばやさの基礎値、補正＝すばやさの補正＋たての補正） |
| 4 | 枠をなくしたあとのボタンの高さ（いまは 56px） | **88px** |

- 1・2 の決め方だと、回避率の計算の結果は v1.14 と **まったく同じ** になる（いまの式も「すばやさの差＋たて」のため）。変わるのは「かいひ」という能力の意味と見せ方で、強さの釣り合い（TC-0024-08 の模擬戦）は変わらない。

## 3. 内容（案）

### 3.1 かいひ と回避の式

| # | 項目 | 案 |
| --- | --- | --- |
| 1 | かいひ（プレイヤー） | 実効値の「かいひ」＝ 実効値の「すばやさ」＋ たての補正。基礎値の「かいひ」＝ 基礎値の「すばやさ」（v1.14 は 0）。補正の「かいひ」＝ すばやさの補正 ＋ たての補正。保存の形（キャラクター）には足さない（いまと同じ） |
| 2 | かいひ（敵） | 敵の「すばやさ」と同じ値（v1.14 は 0） |
| 3 | 回避率 | `evadeChance(受ける側のかいひ, 攻撃する側のすばやさ) = clamp(受ける側のかいひ − 攻撃する側のすばやさ, 0, 90)`（v1.14 は `clamp(受ける側の速 − 攻撃側の速 + 受ける側のかいひ, 0, 90)`）。例：かいひ 50 − すばやさ 30 = 20 → 20%。差がマイナスなら 0%。**どんなに差が開いても 10% は当たる**（上限 90%） |
| 4 | たて | 「かいひ」を上げる（いまと同じ。名前・幅・段階も同じ） |
| 5 | 乱数 | いまと同じ（回避率 0% でも回避の乱数を 1 個引く）。同じシードで同じ結果になる |
| 6 | 表示 | 宿屋・ステータス画面の「かいひ」の行は「 11 (+6)」の形（補正があるときだけ ` (+n)`。v1.14 の「` (+n)` を付けない」をやめる）。装備画面の のうりょく は「 11 =   5 + 6」。ウィンドブーツ（すばやさ）の候補にカーソルを合わせると、すばやさ と かいひ の 2 行が変わる |

### 3.2 スマートフォンの戦闘のボタン

| # | 項目 | 案 |
| --- | --- | --- |
| 1 | 枠 | 狭い画面（599px 以下）の戦闘では、コマンドを囲むウィンドウ（見出し「コマンド」）を出さない。ボタンだけを横 1 列に置く（左右の位置は、ほかのウィンドウの外枠にそろえる） |
| 2 | ボタンの高さ | 56px → **88px**。幅 2：1：1（`grid-template-columns: 2fr 1fr 1fr`）・間 8px・文字の大きさ・色・カーソルの見せ方はいまと同じ |
| 3 | 読み上げ | 見出し「コマンド」はなくなるが、ボタンの箱の `role="menu"`・`aria-label="戦闘"` で「戦闘」のメニューとして読まれる（いまと同じ） |
| 4 | 広い画面 | いまと同じ（右下のウィンドウ「コマンド」に縦の 3 行） |
| 5 | 画面の高さ | 枠と見出しの分（約 40px）が減り、ボタンが 32px 高くなるので、いまの 638px とほぼ同じ（414 × 715・375 × 667 で収まる見込み。実装のあとに測る） |
