## 1. 経緯と元の依頼

依頼 v1.23（敵の絵を v6 に）の 04 詳細設計の準備で、次のことが分かった。依頼 v1.23 の影響の一覧には入っていなかった（見落とし）。

- アプリのアイコンは、敵の絵 `public/enemies/necromancer.png` を切り抜いて作っている（仕様書 §30.5、v1.22）。テスト（TC-0002-08、`tests/scripts/icons.test.ts`）は、コミットしたアイコンが、いまの `necromancer.png` から作り直したものと同じかを確かめる。
- そのため、ネクロマンサーの絵を v6 にすると、アイコンも v6 の絵から作り直すことになる（作り直さないとテストが落ちる）。

v6 の絵から今と同じ切り抜き（左上 (26, −16)・一辺 198）で作ると、図柄が右に寄る（左の余白 44・右 7）。見比べのモック（https://claude.ai/artifact/HqgaHwkNC9Uq498p1YfvxM の「アプリのアイコン」の欄）で見てもらい、オーナーの依頼を受けた。

```
アイコンの画像を、右と左の空間が同じ幅になるように調整してください
```

左右をそろえた案（§3）をモックに出し、オーナーが決めた。

```
この案で進めてください
```

## 2. 調べたこと（2026-11-17）

- v6 のネクロマンサー（付属の情報を取り除いたもの。仕様書 v1.23 §13.1 の `necromancer.png`）で、アイコンに入る行（上から 0〜182 行）の中に純黒でない点がある横の範囲は **70〜216**（幅 147）。明るさの基準を 1・16・32・48 と変えても、端は 70〜72・215〜216 でほぼ同じ。
- 左右の余白をそろえるには、余白の合計（一辺 − 147）が偶数になる必要がある。一辺 198 では 51 で、どちらかが 1 点多くなる。**一辺 199 にすると、左上の x が 44 で、左右とも 26 になる**。
