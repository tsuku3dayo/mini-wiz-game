# US-0002 ホーム画面に追加する

- エピック：[MWIZ-EP-0001](MWIZ-EP-0001-epic-ja.md)（アプリとして届け、通信なしでも遊べる（土台））
- 優先順位：2 / 38（段階 1）

## ストーリー

**スマートフォンでくり返し遊ぶ人として**、このゲームをホーム画面に追加して、アプリのように開きたい。**すぐに続きを遊べる** ようにするため。

## 受け入れ条件

- [ ] タイトル画面に「インストール」のボタンがあり、押すと案内が開く。案内には今の端末（iPhone・Android・PC）の手順が開いて出る（§11.12、§16.6）
- [ ] ブラウザがすぐにインストールできるときは「今すぐインストール」が出る。「とじる」・Esc で閉じ、フォーカスが「インストール」に戻る（§11.12）
- [ ] インストール済みなら「インストール」を出さない（§16.6）
- [ ] ホーム画面に追加でき、アプリ名「WIZ」が切れずに出る。追加したアプリから起動して遊べる（§16.6）

## 確かめ方

案内の表示は自動（E2E）。ホーム画面への追加とアプリ名は、iPhone・Android の実機で手動。
