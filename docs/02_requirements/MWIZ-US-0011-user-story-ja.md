# US-0011 メッセージを読む

- エピック：[MWIZ-EP-0002](MWIZ-EP-0002-epic-ja.md)（キャラクターを作り、宿屋を拠点に遊ぶ）
- 優先順位：11 / 38（段階 2）

## ストーリー

**プレイヤーとして**、操作の結果を 1 行ずつ読み、急ぐときは飛ばしたい。**何が起きたかを見落とさず、待たされすぎない** ようにするため。

## 受け入れ条件

- [ ] メッセージは 400ms ごとに 1 行ずつ出て、最大 4 行。クリック（タップ）・Enter で残りがすぐ出る（§16.4）
- [ ] メッセージを出している間は、ほかの操作を受け付けない（二重に送らない）（§11.8、§11.10）
- [ ] 応答が 300ms を超えると、メッセージ欄の右下に ▼ が点滅する（§16.4）
- [ ] 行の色は、ふつう・success・danger・レアリティで分かれる。danger の行があるとウィンドウの外側の線が赤になる（§11.8）

## 確かめ方

メッセージの進め方は自動（単体テスト）。表示は自動（E2E、テスト用の入口で応答を遅らせる）。
