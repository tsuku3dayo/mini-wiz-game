# US-0028 装備を付け替える

- エピック：[MWIZ-EP-0006](MWIZ-EP-0006-epic-ja.md)（装備を集めて強くする）
- 優先順位：28 / 38（段階 6）

## ストーリー

**プレイヤーとして**、拾った装備を付け替えて、能力値がどう変わるかを見ながら強くしたい。**より強い装備で深い階へ挑める** ようにするため。

## 受け入れ条件

- [ ] 宿屋・ダンジョンのメニューの「そうび」で装備画面が開き、部位ごとの装備と「のうりょく」（「 30 =  18 + 12」の形）が出る（§8.7、§11.7）
- [ ] 付け替えは確認なしで即時、前の個体は所持品の末尾に戻る。満杯でも付け替えはできる（§16.3）
- [ ] 満杯で「はずす」は 409「もちものが いっぱいで はずせない」、空き枠は「なにも そうびしていない」（§16.3）
- [ ] 戦闘中・SWAP・CLEARED では そうび・はずす・すてる が 409 invalid_state（§16.3）
- [ ] 外して上限が下がると HP は最低 1、MP は 0 まで切り詰め、付けても現在値は増えない（§16.3）
- [ ] 装備画面の候補は強い順（段階 → 補正値 → 名前 → 新しい順）、「つよい じゅん」（§16.3）
- [ ] 候補にカーソルを合わせると「 23 →  28 ↑」（緑）／「↓」（橙）、変わらない能力は「 30 =  18 + 12」（§16.3）
- [ ] ソロモンのゆびわは こうげき・ぼうぎょ の両方に同じ補正値が足され、表示は 2 つ並ぶ（§16.3）

## 確かめ方

自動（単体テスト・E2E）。
