# US-0019 敵とたたかう

- エピック：[MWIZ-EP-0004](MWIZ-EP-0004-epic-ja.md)（敵と戦い、強くなる）
- 優先順位：19 / 38（段階 4）

## ストーリー

**プレイヤーとして**、コマンドを選んで敵とたたかいたい。素早さで先に動いたり攻撃をかわしたりしたい。**能力値が育つほど有利になる手応えを感じられる** ようにするため。

## 受け入れ条件

- [ ] 戦闘画面に、敵の名前・ステータス（compact）・コマンド（たたかう／ヒール／にげる）・メッセージ欄が出る。敵の HP は出さない（§11.5）
- [ ] `damage(5,2,0)=4`、`damage(5,2,2)=6`、`damage(4,12,0)=1`、`damage(2,10,2)=1`（§16.1）
- [ ] 素早さが同じならプレイヤーが先に行動する（§16.1）
- [ ] `evadeChance(10,10)=5`、`(11,10)=7`、`(22,10)=29`、`(23,10)=30`、`(5,10)=5`（§16.1）
- [ ] 回避されたらダメージ 0 で、ダメージの乱数（`int(0,2)`）を消費しない（§16.1）
- [ ] 先攻のプレイヤーが敵を倒すと敵は行動しない（乱数は攻撃 1 回分 ＋ ドロップ分だけ）（§16.1）
- [ ] 回避率 15%（回避側速 10・攻撃側速 5）で固定シード 10,000 回の回避割合が 13.5%〜16.5%（§16.1）
- [ ] ダメージを受けると HP の値が 200ms 点滅する。HP が最大の 25% 以下で HP の行が橙になり「！」が付く（§11.5、§11.6）
- [ ] HP × 5 ≦ 最大HP のあいだ、すべてのウィンドウの二重線が #FF5A4E になり、回復すると白に戻る（§16.4）

## 確かめ方

自動（単体テスト・E2E）。
