# US-0013 ダンジョンに出発する

- エピック：[MWIZ-EP-0003](MWIZ-EP-0003-epic-ja.md)（迷宮を探索する）
- 優先順位：13 / 38（段階 3）

## ストーリー

**プレイヤーとして**、宿屋から出発するたびに新しい迷宮に挑みたい。**毎回ちがう探索を楽しめる** ようにするため。

## 受け入れ条件

- [ ] 出発するたびに 5 階層・各 10×10 が新しく作られ、1F の入口に北向きで立つ。HP・MP は回復しない。メッセージ「ダンジョンに ふみこんだ」（§4.5、§16.2）
- [ ] シード 1〜1,000 の生成で、全階が外周壁・両側一致・全マス到達可能、階段とボスの配置が表どおり、目標が最遠かつ 5 歩以上（§16.2）
- [ ] 同じシードから同じ 5 階層ができる。生成は 1 回 50 ms 未満（§16.2）
- [ ] `SeededRng(2026)` の生成結果が参考値（初期位置 (9,1) 北、後続乱数 696131、ハッシュ先頭 `18a58bdf4b596269`）と一致する（§16.2）

## 確かめ方

自動（単体テスト）。
