# US-0021 ヒールで回復する

- エピック：[MWIZ-EP-0004](MWIZ-EP-0004-epic-ja.md)（敵と戦い、強くなる）
- 優先順位：21 / 38（段階 4）

## ストーリー

**プレイヤーとして**、戦闘中やダンジョンの中で、MP を使って HP を回復したい。**宿屋に戻らずに探索を続けられる** ようにするため。

## 受け入れ条件

- [ ] ヒールで HP 10/46・MP 10 → HP 40・MP 7。HP 36/46 なら回復 10、HP 46/46 なら回復 0 で MP は 7（§16.1）
- [ ] MP 2 で `heal` を送ると 409「MP が たりない」。状態が変わらず乱数を消費しない（§16.1）
- [ ] ダンジョンのメニューの「ヒール」で回復できる。使ってもメニューは開いたまま（§11.4）
- [ ] ダンジョンのヒールは場所 DUNGEON 以外（INN・BATTLE・SWAP・CLEARED）では 409。位置・踏破記録・実績を変えない（§16.1）

## 確かめ方

自動（単体テスト・E2E）。
