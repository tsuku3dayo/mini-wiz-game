# EP-0008 敵の姿を見る

## 目的

戦闘画面に、敵 6 体の絵（256×256）を出す。

## 範囲

- 敵の絵 6 枚を置くこと（オーナーが用意した `docs/requests/monster/monster_*_pixel256_black_v5.png` から付属の情報を取り除いて（仕様書 §13.3。絵の点は変えず、背景の真っ黒はそのまま）`public/enemies/` に。v1.19 で差し替えた。v1.11〜v1.18 は v4 に外側の黒を透明にする加工をしたもの、v1.6〜v1.10 は 256×256 の v3、v1.5 は 256×256 の v2、v1.4 は 128×128 の v2 の絵を 2 倍にしていた。v1.18 までは背景透過・半透明の点があってもよい）と確かめ（MD5・256×256）、戦闘の敵のウィンドウの中の背景（真っ黒。v1.6）、表示の大きさ（どの画面も 256px。拡大しない）・読めないときの扱い

含めないもの：絵を描くこと（オーナーが用意した絵を使う）。
