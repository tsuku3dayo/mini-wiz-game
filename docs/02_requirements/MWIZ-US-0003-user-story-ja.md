# US-0003 通信なしで遊ぶ

- エピック：[MWIZ-EP-0001](MWIZ-EP-0001-epic-ja.md)（アプリとして届け、通信なしでも遊べる（土台））
- 優先順位：3 / 38（段階 1）

## ストーリー

**電車の中など電波の弱い所で遊ぶ人として**、通信がなくても起動して遊びたい。**場所を選ばずに続きを遊べる** ようにするため。

## 受け入れ条件

- [ ] 一度開いた後、通信を切っても、起動・プレイ・セーブ・つづきからができる（敵の絵も出る）（§16.6）
- [ ] 画面・敵の絵をすべて事前に保存する（Service Worker の事前キャッシュ）（§11.12、§30.1）

## 確かめ方

自動（E2E で通信を切って起動）と、実機で機内モードにして手動。
