# US-0027 敵が装備を落とす

- エピック：[MWIZ-EP-0006](MWIZ-EP-0006-epic-ja.md)（装備を集めて強くする）
- 優先順位：27 / 38（段階 6）

## ストーリー

**プレイヤーとして**、敵を倒すと装備を落としてほしい。たまに珍しい装備が出てほしい。**倒すたびに期待でき、装備集めを楽しめる** ようにするため。

## 受け入れ条件

- [ ] 32 種の名前・部位・段階・上がる能力・幅がマスタの表のとおり。ID は「部位＋段階」（§16.3）
- [ ] 補正値は `floor(int(min,max) × 倍率×10 ÷ 10)`。LG のエクスカリバーは 60〜78（§16.3）
- [ ] 段階 1〜3 は N/R、4〜5 は R/SR、6〜7 は SR/UR、8 は LG。レアリティの乱数 80 で低い方、81 で高い方（§16.3）
- [ ] スライムはドロップ判定の乱数 15 で落とし、16 で落とさず、以降の乱数を引かない（§16.3）
- [ ] ダークナイトは特例の乱数 5 で段階 8（段階の乱数を引かない・LG）、6 で段階 5〜7（§16.3）
- [ ] ボスは必ず段階 8・LG を落とす（ドロップ判定の乱数が 100 でも）（§16.3）
- [ ] 乱数の順は ドロップ判定 →（ダークナイトのみ）特例 → 部位 → 段階 → レアリティ → 補正値。経験値の成長の後に引く（§16.3）
- [ ] ドロップの行は「〇〇は 名前［R］（能力 +n）を おとした！」で、行の色がレアリティの色。UR・LG は点滅する（§16.3）
- [ ] 個体の ID は nextId から振り、捨てても再利用しない。満杯の入れ替え待ちにも ID が振られる（§16.3）

## 確かめ方

自動（単体テスト・E2E）。
