# US-0005 起動に失敗しても直る

- エピック：[MWIZ-EP-0001](MWIZ-EP-0001-epic-ja.md)（アプリとして届け、通信なしでも遊べる（土台））
- 優先順位：5 / 38（段階 1）

## ストーリー

**遊ぶ人として**、古いデータのせいで起動しなくなっても、自分で直して遊び続けたい。**記録を失わずに元に戻せる** ようにするため。

## 受け入れ条件

- [ ] 起動に失敗したとき（8 秒たっても画面が動かない）、このアプリのキャッシュだけを消して 1 回だけ自動で読み込み直す（§11.12、§16.6）
- [ ] 2 分以内に続けて失敗したら「うまく起動できませんでした。」「なおす」「きろくは消えません。」が出る（§11.12、§16.6）
- [ ] どちらでもプレイ中の状態・セーブ・音の設定は消えない（§16.6）

## 確かめ方

自動（E2E、見張りの待ち時間を短くして起動を止める）。
