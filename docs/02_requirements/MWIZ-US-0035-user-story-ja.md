# US-0035 スマートフォンの画面で快適に遊ぶ

- エピック：[MWIZ-EP-0010](MWIZ-EP-0010-epic-ja.md)（スマートフォンで快適に、誰でも使える（品質））
- 優先順位：35 / 38（段階 10）

## ストーリー

**スマートフォンで遊ぶプレイヤーとして**、どの画面も縦画面に収まり、指で押しやすくしてほしい。**片手で、ストレスなく最後まで遊べる** ようにするため。

## 受け入れ条件

- [ ] スマートフォン（幅 375px・高さ 667px）で、どの画面も横にはみ出さず、すべての操作がタップでできる。ボタンは 48px 以上、メニューの行は 44px 以上（指で触る画面。マウスで操作する広い画面では 25.6px に詰まる）。iPhone 11 の Safari（414 × 715）では、どの画面も 1 画面に収まる（§16.4）
- [ ] ノッチ・ホームバー・ステータスバーに内容が入り込まない（ホーム画面のアプリとして開いたときも）（§16.6）
- [ ] 操作するとき、指で疑似3D・メッセージなど大事な表示が隠れない（§11.1。03 の試作で配置を決める）
- [ ] ページの拡大を禁止しない（§11.11）
- [ ] 端末のフォントで、文字が読める大きさ・色で出る。ステータスの数字の桁がそろう（§11.3）
- [ ] PC の広い画面（幅 600px 以上）でも、配置が崩れない（§11.1）

## 確かめ方

はみ出し・ボタンの大きさは自動（E2E の `pixel7`・`small`・`desktop`）。指で隠れないか・読みやすさは、03 の試作と各 WS の終わりに iPhone・Android の実機で手動。
