# US-0030 もちものが満杯のとき入れ替える

- エピック：[MWIZ-EP-0006](MWIZ-EP-0006-epic-ja.md)（装備を集めて強くする）
- 優先順位：30 / 38（段階 6）

## ストーリー

**プレイヤーとして**、もちものが満杯のときに装備を落とされても、何かを捨てて拾うか、あきらめるかを選びたい。**良い装備を取り逃さない** ようにするため。

## 受け入れ条件

- [ ] 所持品 50 個（装備中は数えない）で落とすと `SWAP`・`/swap`。再読み込みしても同じ個体で再開し、ほかの操作は 409 invalid_state（§16.3）
- [ ] 入れ替えの画面に「もちものが いっぱいだ」「おちている：」と落ちている装備、「ひろう（すてるものを えらぶ）」「あきらめる」が出る（§11.5）
- [ ] 拾うと捨てた個体が消えて拾った個体が末尾に入り 50 個のまま、あきらめると所持品は変わらない。どちらも DUNGEON へ（ボス後は CLEARED・クリアの行・自動セーブ）（§16.3）
- [ ] 所持品 50 個でボスを撃破すると場所 SWAP・周回数は既に 2・クリアの行はまだない。入れ替えをあきらめると CLEARED になり最後の行がクリアの行（§16.1）

## 確かめ方

自動（単体テスト・E2E）。
