# EP-0002 キャラクターを作り、宿屋を拠点に遊ぶ

## 目的

タイトル画面からキャラクターを作り、宿屋で休み・セーブし、あとで続きから遊べるようにする。どの画面でも共通のメニュー・メッセージ欄・エラーの出し方を、ここで作る。

## 範囲

- タイトル画面・名前入力・宿屋の画面、画面の切替え（ハッシュ・LocationGuard）
- キャラクターの作成（名前の規則・初期値）、やすむ、セーブ・つづきから・タイトルへ戻る、プレイ中の状態の保存
- 共通の部品：ウィンドウ・メニュー（カーソル・確認・GameMenu の骨組み）・メッセージ欄（逐次表示・スキップ・応答待ち）・ErrorPanel
- ゲーム API と端末内保存（できない操作・保存の失敗・壊れた値）

含めないもの：ダンジョン（EP-0003）、メニューの そうび・もちもの（EP-0006）・ステータス（EP-0005）、音（EP-0007・0009）。
