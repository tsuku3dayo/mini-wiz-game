# US-0010 メニューとコマンドを操作する

- エピック：[MWIZ-EP-0002](MWIZ-EP-0002-epic-ja.md)（キャラクターを作り、宿屋を拠点に遊ぶ）
- 優先順位：10 / 38（段階 2）

## ストーリー

**プレイヤーとして**、どの画面でも同じやり方でメニューを選びたい。**迷わず、押し間違えずに操作できる** ようにするため。

## 受け入れ条件

- [ ] すべての CommandMenu で、↑↓ のカーソルは端で止まる。Enter・Space・クリック（タップ）で決定する（§16.4）
- [ ] 選べない項目を決定すると、その理由がメッセージ欄に出る（例：「MP が たりない」）。メッセージ欄のないタイトル画面では何も出さない（§11.4、§11.5）
- [ ] 宿屋・ダンジョンのメニューは「もどる」が一番上で、初めのカーソルはその次（ダンジョンは MP 不足でも ヒール）。Esc で閉じ、フォーカスがメニューボタン（宿屋は「メニュー」）に戻る。広い画面ではメニューに「ステータス」がなく、宿屋に能力と実績が出る（§16.4）
- [ ] 確認の初めのカーソルは「いいえ」、Esc は「いいえ」、Tab でメニューの外へ出ない（§16.4）
- [ ] メニューの「おと」で音を切り替えても、メニューは閉じない（§11.4）

## 確かめ方

カーソルの動きは自動（単体テスト）。画面は自動（E2E）。
