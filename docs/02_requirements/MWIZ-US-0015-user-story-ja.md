# US-0015 自動地図で踏破したところを確かめる

- エピック：[MWIZ-EP-0003](MWIZ-EP-0003-epic-ja.md)（迷宮を探索する）
- 優先順位：15 / 38（段階 3）

## ストーリー

**プレイヤーとして**、歩いたところが地図に残ってほしい。**迷わずに探索でき、まだ行っていない所が分かる** ようにするため。

## 受け入れ条件

- [ ] 踏破記録：立ったマスだけが地図に出る。回転・壁では増えない。ボスのマスは記録しない。階を移っても前の階の記録が残る（§16.2）
- [ ] 自動地図は踏破済みマスだけを 16px で塗り、壁の線・↓↑入・現在地の ▲▶▼◀ を描く。座標は出さない（§16.4）
- [ ] ゲーム API の結果にマップ全体・未踏破マス・ほかの階・ボス位置・敵の HP・revision が含まれない（§16.2）

## 確かめ方

自動（単体テスト・E2E）。
