# US-0017 宿屋へ戻る

- エピック：[MWIZ-EP-0003](MWIZ-EP-0003-epic-ja.md)（迷宮を探索する）
- 優先順位：17 / 38（段階 3）

## ストーリー

**プレイヤーとして**、1F の入口から宿屋へ戻りたい。**危なくなる前に休み、セーブできる** ようにするため。

## 受け入れ条件

- [ ] 1F の入口でだけ宿屋に戻れる（「宿屋に もどった」）。ほかでは 409「入口に いないため もどれません」（§16.2）
- [ ] 戻っても HP・MP は回復しない。経験値・所持品は引き継ぐ（§4.5、§7.3）
- [ ] 戻ってもマップ（5 階層の形・階段・ボスの位置）と踏破記録は残り、次に出発すると、乱数を引かずに同じマップの 1F の入口に北向きで立つ。敗北・クリアのあとの出発では新しいマップになる。宿屋にいる間は、マップを画面に渡さない（戻ったときの得と、敗北の損をつけるため。§4.5、§4.6、§16.2。v1.1。仕様書 v1.22。v1.0 では「ダンジョンは消える」）

## 確かめ方

自動（単体テスト・E2E）。
