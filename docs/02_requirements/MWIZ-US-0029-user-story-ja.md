# US-0029 もちものを見て捨てる

- エピック：[MWIZ-EP-0006](MWIZ-EP-0006-epic-ja.md)（装備を集めて強くする）
- 優先順位：29 / 38（段階 6）

## ストーリー

**プレイヤーとして**、持っている装備を一覧で見て、いらないものを捨てたい。**所持品を整理して、新しい装備を拾える** ようにするため。

## 受け入れ条件

- [ ] メニューの「もちもの」で一覧が開き、「もちもの 23／50」が出る。50 個で橙と「！」。0 個は「なにも もっていない」（§16.3）
- [ ] もちもの画面・入れ替え画面は弱い順（段階・補正値・名前を逆、最後の新しい順はそのまま）、「よわい じゅん」（§16.3）
- [ ] 「◀ すべて ▶」で すべて → ぶき → よろい → たて → アクセ と循環し、「すべて」だけ部位を添える（§16.3）
- [ ] 個体を選ぶと「{装備名}［{ランク}］を すてますか？」が出る。はい で捨て、いいえ で同じ個体にカーソルが戻る（§8.7）
- [ ] 装備中の個体は捨てられない（「その もちものは ない」）（§16.3）
- [ ] セーブ・自動セーブに装備・所持品が入り、つづきからで戻る。入れ替え待ちは保存しない（§16.3）
- [ ] 倒れても装備・所持品を失わない。はじめからは空（§16.3）
- [ ] 古いデータの合わない個体は読み込み時に直り、マスタにない種類は取り除いて警告ログ（§16.3）

## 確かめ方

自動（単体テスト・E2E）。
