# EP-0010 スマートフォンで快適に、誰でも使える（品質）

## 目的

スマートフォンの縦画面で、はみ出さず、指で押しやすく、すばやく反応するようにする。キーボード・読み上げでも遊べるようにする。画面の動きを自動テストで確かめられる入口を用意する。

## 範囲

- 画面の大きさ（375 × 667 以上）・ボタンの大きさ・安全領域・PC の広い画面
- キーボードだけの操作・フォーカス・読み上げ・axe-core の検査
- 応答時間・起動の時間・遭遇の音の遅れ
- テスト用の入口（`?debug=1`）

この epic は非機能の要件で、ほかの epic の中で最初から守る（ボタンの大きさ・ARIA・フォーカスなど）。この epic のストーリーでは、全体を通した確認と仕上げを行う。
