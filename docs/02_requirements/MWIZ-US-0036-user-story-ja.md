# US-0036 キーボード・読み上げでも遊べる

- エピック：[MWIZ-EP-0010](MWIZ-EP-0010-epic-ja.md)（スマートフォンで快適に、誰でも使える（品質））
- 優先順位：36 / 38（段階 10）

## ストーリー

**キーボードや読み上げ（スクリーンリーダー）を使うプレイヤーとして**、マウスや画面を見なくても状況が分かり、操作できるようにしてほしい。**誰でも最後まで遊べる** ようにするため。

## 受け入れ条件

- [ ] すべての操作がキーボードだけでできる。フォーカスリングが見える（§11.11、§14）
- [ ] メニュー系を閉じたら、フォーカスが開いたボタン・項目に戻る。確認・メニューではフォーカスが外へ出ない（§11.11）
- [ ] 音だけで情報を伝えない（すべてメッセージ欄に文で出す）。色だけに頼らない（HP の「！」・［SR］など）（§11.11、§14）
- [ ] 疑似3D と地図に説明文（例：「3F 北を向いている。前方 2 マス先は かべ。…」「3F の地図。踏破済み N マス。」）がある（§11.5）
- [ ] すべての画面で axe-core の違反がない（§16.4）

## 確かめ方

自動（E2E：`desktop` でキーボードだけの通しの操作、axe-core）。読み上げの聞こえ方は、PC か実機の読み上げ機能で手動（できなかったときは attested-computation の「確認できなかったこと」に書く）。
