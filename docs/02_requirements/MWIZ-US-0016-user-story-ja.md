# US-0016 階段で階を移る

- エピック：[MWIZ-EP-0003](MWIZ-EP-0003-epic-ja.md)（迷宮を探索する）
- 優先順位：16 / 38（段階 3）

## ストーリー

**プレイヤーとして**、階段を見つけて下の階へ降りたり、上の階へ戻ったりしたい。**深い階へ挑み、危ないときは引き返せる** ようにするため。

## 受け入れ条件

- [ ] 下り階段で「↓」→ 次の階の上り階段に同じ向きで立ち「nF に おりた」。2F 以上の上り階段で「↑」→ 前の階の下り階段に立ち「nF に のぼった」。それ以外は 409（§16.2）
- [ ] 足元のボタンは足元に応じて「↓ おりる」「↑ のぼる」「宿屋へ戻る」のどれか 1 つ。ないときもメニューボタンの位置は変わらない（§16.4）
- [ ] 階段・入口のマスに着いたとき、メッセージ欄に案内が 1 行出る。その場で向きを変えても繰り返さない（§16.4）

## 確かめ方

自動（単体テスト・E2E）。
