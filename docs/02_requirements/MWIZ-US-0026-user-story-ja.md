# US-0026 実績とステータスを見る

- エピック：[MWIZ-EP-0005](MWIZ-EP-0005-epic-ja.md)（ボスを倒し、周回して記録を残す）
- 優先順位：26 / 38（段階 5）

## ストーリー

**プレイヤーとして**、これまでの戦いの回数や周回数、今の能力値を見たい。**自分の歩みを振り返り、次の目標を立てられる** ようにするため。

## 受け入れ条件

- [ ] ボス撃破で実績が `{ battles: 1, kills: 1, deaths: 0, laps: 2, bossKills: 1 }`（初期から 1 戦目で撃破した場合）（§16.1）
- [ ] 逃走成功は battles だけが増える。通常の勝利は kills だけが増え、bossKills・laps は変わらない（§16.1）
- [ ] 保存値がおかしい項目は初期値に直す（例：`{ battles: -1, kills: 1.5, deaths: "2", laps: 0, bossKills: 3 }` → `{ 0, 0, 0, 1, 3 }`）（§9.4）
- [ ] 狭い画面では、宿屋・ダンジョンのメニューの「ステータス」で、能力値（補正つき）と「じっせき」（そうせんとう・とうばつ・しぼう・しゅうかい・ボスとうばつ）が出る。もどる・Esc で閉じる（§11.7）
- [ ] 広い画面では、宿屋の画面に能力値（補正つき）と「じっせき」が並んで出る（メニューに「ステータス」はない）（§11.5、§11.7）

## 確かめ方

自動（単体テスト・E2E）。
