# EP-0001 アプリとして届け、通信なしでも遊べる（土台）

## 目的

公開 URL を開くだけで遊べ、ホーム画面に追加でき、通信なしでも起動し、新しい版に安全に切り替えられ、起動に失敗しても直るようにする。あわせて、CI・GitHub Pages への公開・PWA の骨組みを最初に用意し、以降の epic を公開 URL と実機で確かめられるようにする。

## 範囲

- 公開（GitHub Pages）と CI（verify・E2E）、PWA の骨組み（manifest・アイコン・Service Worker）
- インストールの案内、オフライン、更新の帯、起動の見張りと復旧
- 保存のキー・キャッシュをほかのアプリと分ける（アプリ識別子）

含めないもの：画面の中身（EP-0002 以降）。
