# US-0006 タイトル画面から始める

- エピック：[MWIZ-EP-0002](MWIZ-EP-0002-epic-ja.md)（キャラクターを作り、宿屋を拠点に遊ぶ）
- 優先順位：6 / 38（段階 2）

## ストーリー

**プレイヤーとして**、タイトル画面から新しい冒険を始めるか、セーブの続きから始めるかを選びたい。**前回の続きをすぐ遊べ、迷わず始められる** ようにするため。

## 受け入れ条件

- [ ] タイトル画面に、飾り線・「WIZ」・「～ 死霊術師の迷宮 ～」・メニュー（はじめから／つづきから／おと）・メッセージ欄・版の表記「v1.0」が出る（§11.5）
- [ ] セーブがあれば「つづきから」にカーソルがあり、右に「{名前} Lv{n}」が出る。なければ「つづきから」は灰色で、選ぶと「セーブデータが ありません」と出る（§16.4）
- [ ] 「はじめから」で名前入力へ移る（§11.5）
- [ ] プレイ中のゲームがないとき、`/` と `/new` 以外の URL を開くと `/` に移る（§16.4）
- [ ] プレイ中のゲームがあるとき、どの URL を開いても場所に対応する画面（`/inn` など）に移る。存在しない URL は `/` を経て同じ画面に移る（§16.4）

## 確かめ方

自動（E2E）。
