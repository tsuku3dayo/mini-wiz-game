# US-0006 タイトル画面から始める

- エピック：[MWIZ-EP-0002](MWIZ-EP-0002-epic-ja.md)（キャラクターを作り、宿屋を拠点に遊ぶ）
- 優先順位：6 / 38（段階 2）

## ストーリー

**プレイヤーとして**、タイトル画面から新しい冒険を始めるか、セーブの続きから始めるかを選びたい。**前回の続きをすぐ遊べ、迷わず始められる** ようにするため。

## 受け入れ条件

- [ ] タイトル画面に、タイトル画像（「WIZミニ ～死霊術師の迷宮～」。読み上げでは見出しとして読まれる。読めないときは文字の「WIZミニ」と副題）・メニュー（はじめから／つづきから／おと／クレジット。クレジットは v1.3 で追加）・インストールのボタン・版の表記「v1.0」が出る。メッセージ欄はない（§11.5）
- [ ] セーブがあれば「つづきから」にカーソルがあり、右に「{名前} Lv{n}」が出る。なければ「つづきから」は灰色で、選んでも何も起きない（§16.4）
- [ ] 「はじめから」で名前入力へ移る（§11.5）
- [ ] プレイ中のゲームがないとき、`/`・`/new`・`/credits` 以外の URL を開くと `/` に移る（§16.4）
- [ ] プレイ中のゲームがあるとき、どの URL を開いても場所に対応する画面（`/inn` など）に移る。存在しない URL は `/` を経て同じ画面に移る（§16.4）

## 確かめ方

自動（E2E）。
