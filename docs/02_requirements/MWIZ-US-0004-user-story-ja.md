# US-0004 新しい版に更新する

- エピック：[MWIZ-EP-0001](MWIZ-EP-0001-epic-ja.md)（アプリとして届け、通信なしでも遊べる（土台））
- 優先順位：4 / 38（段階 1）

## ストーリー

**遊び続けている人として**、新しい版が出たら、遊んでいる途中を邪魔されずに、好きなときに切り替えたい。**途中の冒険を失わずに新しい版で遊べる** ようにするため。

## 受け入れ条件

- [ ] 新しい版を公開すると、タイトル・宿屋の画面で「新しい版があります」と「更新」が出る（§16.6）
- [ ] ダンジョン・戦闘などの途中では出ない（§11.12、§16.6）
- [ ] 「更新」で新しい版に切り替わり、プレイ中の状態とセーブは消えない。勝手には切り替わらない（§11.12、§16.6）

## 確かめ方

帯の表示は自動（E2E、テスト用の入口で帯を出す）。実際の公開での更新は、WS の終わりの手動テスト。
