# US-0037 すばやく反応する

- エピック：[MWIZ-EP-0010](MWIZ-EP-0010-epic-ja.md)（スマートフォンで快適に、誰でも使える（品質））
- 優先順位：37 / 38（段階 10）

## ストーリー

**プレイヤーとして**、操作したらすぐに画面が変わり、すぐに起動してほしい。**テンポよく探索できる** ようにするため。

## 受け入れ条件

- [ ] 各操作（ゲーム API の呼び出しから画面の更新まで）が 100 ms 未満（§14）
- [ ] タイトル画面の初期表示が 1 秒以内（2 回目以降の起動、スマートフォンの実機）（§14）
- [ ] 遭遇してから最初の音が鳴るまで 0.1 秒以内、遭遇の音全体は 1 秒以内（§14）
- [ ] 5 階層の生成が 1 回 50 ms 未満（§16.2）

## 確かめ方

生成の時間とゲーム API の処理時間は自動（単体テスト）。画面の更新・起動の時間・音の遅れは、実機で手動（目安の計測）。
