# US-0032 効果音を鳴らす・切り替える

- エピック：[MWIZ-EP-0007](MWIZ-EP-0007-epic-ja.md)（演出と効果音で盛り上げる）
- 優先順位：32 / 38（段階 7）

## ストーリー

**プレイヤーとして**、遭遇やレベルアップのときに効果音を聞きたい。音を出せない場所では消したい。**気分が盛り上がり、場所に合わせて遊べる** ようにするため。

## 受け入れ条件

- [ ] 初めて開いたとき、タイトルのメニューに「おと：オフ」と出て、音は鳴らない（§16.5）
- [ ] 「おと：オフ」を選ぶと「おと：オン」に変わり、短い確認音が鳴り、メッセージ欄に「おとを オンにした」と出る。端末内保存の `mini-wiz-game-sound` が `on` になる（§16.5）
- [ ] 開き直しても「おと：オン」のまま（§16.5）
- [ ] 端末内保存に書けない環境でも、その場では切り替わる（§16.5）
- [ ] ゲーム中の「メニュー → おと」でも切り替えられ、メニューは閉じない。オフにしたとき確認音は鳴らない（§16.5）
- [ ] 音がオンで通常の敵に遭遇すると、メッセージ欄が消えて 680 ms の遭遇音が鳴る。戦闘中のターンでは鳴らない（§16.5）
- [ ] ボスとの遭遇では遭遇音は鳴らず、ボス出現の音（1.2 秒）が鳴る（§16.5）
- [ ] レベルアップ・UR のドロップ・LG のドロップ・ボス撃破・クリアの行が表示された瞬間に、それぞれの音が鳴る（LG は長いほう）（§16.5）
- [ ] 演出中に Enter / Space またはメッセージ欄のクリックで飛ばすと、音がすぐ止まる（§16.5）
- [ ] 音がオフのときは、どの出来事でも鳴らない（§16.5）
- [ ] Web Audio が使えないブラウザでも、エラーなく遊べる（§16.5）
- [ ] 操作前に suspended だった場合、最初のタップ・クリック／キー（Shift だけは除く）で音が出るようになる。iPhone の Safari でも、最初のタップで音が出る（§16.5）
- [ ] 各音の波形・周波数・長さが §25.2 の表と同じ（§16.5）

## 確かめ方

音色と鳴らす判断は自動（単体テスト：偽の Web Audio、E2E：`app:sound` イベント）。実際の聞こえ方・iPhone での鳴り方は実機で手動。
