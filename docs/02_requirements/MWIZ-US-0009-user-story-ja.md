# US-0009 セーブして、つづきから再開する

- エピック：[MWIZ-EP-0002](MWIZ-EP-0002-epic-ja.md)（キャラクターを作り、宿屋を拠点に遊ぶ）
- 優先順位：9 / 38（段階 2）

## ストーリー

**プレイヤーとして**、宿屋で冒険をセーブし、あとで続きから再開したい。また、閉じてしまっても今の状態から続けたい。**少しずつ遊び進められる** ようにするため。

## 受け入れ条件

- [ ] セーブは 3 スロット。宿屋の「セーブ」でスロットの一覧（もどる／スロット1〜3）が出て、空きを選ぶとすぐ書き、中身のあるスロットを選ぶと「スロット{n}（{名前} Lv{n}）に うわがきしますか？」（初めは いいえ）が出る。メッセージ「スロット{n}に セーブしました」。セーブは宿屋でだけでき、プレイ中状態は「最後に使ったスロット」だけが変わる（§11.5、§16.2、§16.4、§21.6。v1.1）
- [ ] つづきからは選んだスロットのセーブで宿屋から再開する。メッセージ「{名前}は 宿屋で めをさました」（§16.2、§21.6）
- [ ] v1.13 までの 1 つのセーブは、新しい版を初めて開いたときスロット 1 に移り、中身は変わらない（§16.2、§21.7。v1.1）
- [ ] 宿屋の「タイトルへ戻る」で確認「プレイ中の ぼうけんは きえます。よろしいですか？」が出る。はい でタイトルへ戻り、いいえ・Esc で元のメニューに戻る（§11.5）
- [ ] 再読み込み・ページを閉じて開き直す・アプリを更新したあとも、プレイ中の状態（戦闘中の敵の残り HP・入れ替え待ちを含む）とセーブが残っている（§16.2）
- [ ] 版 1〜5 のゲーム状態、版 1・2 のセーブを読み込める（移行内容は §21.4 の表どおり）（§16.2）

## 確かめ方

自動（単体テスト：ゲーム API と移行、E2E：再読み込み）。
