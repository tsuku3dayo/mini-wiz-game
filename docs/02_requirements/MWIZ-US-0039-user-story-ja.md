# US-0039 クレジットを見る

- エピック：[MWIZ-EP-0002](MWIZ-EP-0002-epic-ja.md)（キャラクターを作り、宿屋を拠点に遊ぶ）
- 優先順位：39（仕様書 v1.12 で、v1.0 の 38 本のあとに足した。EP-0001 の段階の表には入れない（段階はすべて終わっているため））

## ストーリー

**プレイヤーとして**、タイトル画面から、このゲームを誰が作ったか（クレジット）を見たい。**作った人の名前と役割が分かる** ようにするため。

## 受け入れ条件

- [ ] タイトル画面のメニューの「おと」の下に「クレジット」の項目があり、ほかの項目と同じ見た目・動き（▶ カーソル・↑↓・Enter・タップ）で選べる。初めのカーソルは変わらない（§11.4・§11.5）
- [ ] 「クレジット」を選ぶと、クレジット画面（`#/credits`）に移る。上の行の左に「← もどる」のボタン、まん中に見出し「クレジット」が出る（§11.5）
- [ ] 役割と名前の 6 組が、上から PRODUCER／DIRECTOR／GAME DESIGNER（つくだ よしはる）、GRAPHIC DESIGNER／SOUND CREATOR／PROGRAMMER（CLAUDE CODE）の順に、中央にそろえて出る。色はゲームのもの（見出しはくすんだ金、役割は古びた灰、名前は羊皮紙の色の太字）（§11.5）
- [ ] 「← もどる」（クリック・タップ・Enter）と Esc で、タイトル画面に戻る。画面を開いたとき、フォーカスは「← もどる」にある（§11.5）
- [ ] 読み上げでは、見出し「クレジット」と、役割と名前の組（説明のリスト）として読まれる。axe-core の違反がない（§11.11）
- [ ] タイトル → クレジット → タイトルのあいだ、タイトルの曲は止まらず、頭に戻らない（§12.2）
- [ ] プレイ中のゲームがあるとき `#/credits` を開くと、場所に対応する画面（宿屋など）に移る（§11.2・§16.4）
- [ ] メニューが 4 行になっても、タイトル画面はエラーの枠が出たときも縦に収まる。クレジット画面は横にはみ出さない（§11.5・§16.4）

## 確かめ方

自動（単体テスト・E2E）と、実機の手動テスト（iPhone・PC：見え方・戻り方・曲が続く）。
