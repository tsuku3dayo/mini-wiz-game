# US-0023 倒れても宿屋で目覚める

- エピック：[MWIZ-EP-0004](MWIZ-EP-0004-epic-ja.md)（敵と戦い、強くなる）
- 優先順位：23 / 38（段階 4）

## ストーリー

**プレイヤーとして**、戦闘で倒れても、育てたキャラクターを失わずにやり直したい。**負けても気軽に再挑戦できる** ようにするため。

## 受け入れ条件

- [ ] 死亡すると場所 INN・HP と MP は実効値の最大まで回復・レベル・経験値・能力値・装備は変わらず・死亡回数 +1・最後の 2 行が「`<名前>`は たおれた…」「気がつくと 宿屋に いた」（§16.1）
- [ ] その戦闘の経験値・ドロップはない。セーブは自動では更新しない（§5.6）
- [ ] 死亡は danger の行を表示した時点で宿屋へ移る（§16.4）

## 確かめ方

自動（単体テスト・E2E）。
