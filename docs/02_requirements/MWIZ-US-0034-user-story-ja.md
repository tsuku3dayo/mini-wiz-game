# US-0034 場面ごとの BGM を聴く

- エピック：[MWIZ-EP-0009](MWIZ-EP-0009-epic-ja.md)（場面ごとの BGM を流す）
- 優先順位：34 / 38（段階 9）

## ストーリー

**プレイヤーとして**、タイトル・宿屋・迷宮・戦闘・ボス戦・クリアで、それぞれの雰囲気に合った曲を聴きたい。**場面に入り込んで遊べる** ようにするため。

## 受け入れ条件

- [ ] 音がオンのとき、タイトル・名前入力で「カタコンベ」、宿屋で「ローエングリン 第 1 幕への前奏曲」、ダンジョンと（通常の）入れ替え画面で「死の島」、戦闘で「火星」、ボス戦で「怒りの日」が流れ、16 小節ごとに頭へ戻って途切れずに繰り返す（§16.5）
- [ ] ボス撃破の演出のあとから宿屋に戻るまで（撃破のメッセージ・入れ替え画面・クリア画面）、「イン・パラディス」が流れる（§16.5）
- [ ] 同じ場面の中（宿屋のメニュー・ステータスの開閉など）では曲が頭に戻らない（§16.5）
- [ ] 曲が変わるとき、前の曲が 0.3 秒で消えて次の曲が頭から始まる（§16.5）
- [ ] 通常の遭遇では、遭遇音が終わってから戦闘の曲が始まる。オンに切り替えたときは確認音のあとにタイトルの曲（§16.5）
- [ ] ボス出現の演出のあいだは無音で、演出が終わる（または飛ばす）とボスの曲が始まる（§16.5）
- [ ] ボスを倒すと、撃破の演出のあいだ曲が止まり、演出が終わる（または飛ばす）と「イン・パラディス」が始まる。撃破のメッセージ・入れ替え画面・クリア画面のあいだ頭に戻らずに続き、「宿屋へ」で宿屋の曲。入れ替え画面・クリア画面で開き直しても「イン・パラディス」（§16.5）
- [ ] 通常の敵に勝つと、メッセージのあいだは戦闘の曲、ダンジョン画面に戻るとダンジョンの曲。倒れると宿屋の曲（§16.5）
- [ ] 効果音が鳴っているあいだ BGM が 3 割の音量に下がり、終わると戻る（§16.5）
- [ ] オフにすると BGM が 0.3 秒で消える（§16.5）
- [ ] エラーの画面（ErrorPanel）でも曲は止まらない（§16.5）
- [ ] 曲データが §26.9 と同じ（`bgm-tracks.test.ts` の諸元・拍数・音域の検査が通り、実機で聴いて確かめる）（§16.5）

## 確かめ方

曲の選び方・予約は自動（単体テスト：偽の Web Audio、E2E：`app:bgm` イベント）。曲の聞こえ方は実機で手動。
