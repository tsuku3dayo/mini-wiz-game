# US-0040 扉を開けて、宝箱や強い敵に出会う

- エピック：[MWIZ-EP-0003](MWIZ-EP-0003-epic-ja.md)（迷宮を探索する）
- 優先順位：40（仕様書 v1.25 で、US-0039 のあとに足した。EP-0001 の段階の表には入れない（段階はすべて終わっているため））

## ストーリー

**プレイヤーとして**、行き止まりの扉を開けて、宝箱や強い敵、下り階段を見つけたい。**どの扉に何があるかを楽しみに迷宮を探し、良い装備を手に入れられる** ようにするため。

## 受け入れ条件

- [ ] 各階の扉は行き止まりの入口にだけあり、1F〜4F は下り階段 1・敵 2・宝箱 2、5F はボス 1・宝箱 4。行き止まりが足りない階は、下り階段・ボスを先にして減る。扉の中身は開けるまで分からない（ゲーム API の結果にも入らない）（§3.6・§16.2）
- [ ] 閉じた扉には進めず「とびらが しまっている」と出て、疑似3D の正面の壁が点滅する。残っている宝箱のマスにも進めず「たからばこが ある」と出る。どちらも乱数を引かず遭遇しない（§4.2・§16.2）
- [ ] 扉の前で扉を向くと、操作の行の「宿屋へ戻る」の場所に「扉をあける」が出る（階段・入口のマスでも、扉を向いているときは「扉をあける」）。向きを変えると足元のボタン（なければなし）に戻る。メニューボタンの位置は変わらない（§11.5・§16.4）
- [ ] 下り階段の扉を開けると「とびらを あけた！」「おくに くだり階段が ある」で扉が消え、中に入ると下りられる（§4.11・§16.2）
- [ ] 宝箱の扉を開けると「たからばこを みつけた！」で宝箱が残り、同じ場所のボタンが「宝箱をあける」になる。開けると「たからばこを あけた！」「たからばこから 名前［R］（能力 +n）を てにいれた！」で必ず 1 個手に入り、宝箱が消える。中身の段階は 1F スライム・2F と 3F ゴブリン・4F スケルトン・5F オークロードのドロップと同じ。50 個なら入れ替えの画面になる（§4.11・§8.4・§16.2・§16.3）
- [ ] 宝箱を開けずに離れても宝箱は残り、また宝箱の方を向くと「宝箱をあける」が出る（§4.11）
- [ ] 敵の扉を開けると、その階の扉の敵（1F ゴブリン・2F スケルトン・3F オークロード・4F ダークナイト）とふつうの遭遇と同じく戦闘になる（メッセージ欄が消え、遭遇の音・入力止め）。勝つと扉が消え、にげると扉は閉じたまま残り、また開けると同じ敵が出る（§4.11・§16.2・§16.4）
- [ ] 5F のボスの扉を開けるとボス戦になる（§4.11・§6.3）
- [ ] 疑似3D に扉の形（正面・左右）と「□ たからばこ」が、自動地図に閉じた扉の辺が描かれる。説明文に「前方は とびら。」などが入る（§11.5・§16.4）
- [ ] 開けた扉・残っている宝箱は、宿屋に戻って出発しても同じ。敗北・クリアのあとの出発では、新しいマップの閉じた扉になる（§3.6・§16.2）

## 確かめ方

自動（単体テスト・E2E）と、実機の手動テスト（iPhone・PC：扉のボタンの出方・扉の見え方・宝箱・扉の敵・遊んだ手ごたえ）。
