# EP-0005 ボスを倒し、周回して記録を残す

## 目的

5F のボス「暗黒のネクロマンサー」を倒してクリアし（クリア時は自動でセーブ）、同じキャラクターで次の周へ進み、これまでの実績と能力値を見られるようにする。

## 範囲

- ボスのマスでのボス戦、ボス撃破の報酬（経験値 1000・段階 8 の装備の抽選はここで呼ぶ）、クリア画面、クリア時の自動セーブ
- 周回（宿屋へ）、周回しても敵は強くならない
- 実績の数え方、ステータス画面（メニューから開く）
- バランス（ボスの勝率の模擬戦）

含めないもの：ボスのドロップの中身（EP-0006）、ボス出現・撃破の演出と音（EP-0007・0009）。
