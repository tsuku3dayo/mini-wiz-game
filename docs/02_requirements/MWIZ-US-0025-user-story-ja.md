# US-0025 次の周へ進む

- エピック：[MWIZ-EP-0005](MWIZ-EP-0005-epic-ja.md)（ボスを倒し、周回して記録を残す）
- 優先順位：25 / 38（段階 5）

## ストーリー

**プレイヤーとして**、クリアした後も同じキャラクターで次の周を遊びたい。**育てたキャラクターでさらに装備集めを続けられる** ようにするため。

## 受け入れ条件

- [ ] 「宿屋へ」で INN・ダンジョンなし・HP/MP/実績は変わらず、メッセージ「`<名前>`は 宿屋に もどった」。2 回目は 409（§16.1）
- [ ] 次に出発するとダンジョンが新しく作られ、5F にボスがまた現れる（§9.3）
- [ ] 周回数 9 でもボスの HP は 260（周回で敵が強くならない）（§16.1）

## 確かめ方

自動（単体テスト：2 周の通しプレイ、E2E）。
