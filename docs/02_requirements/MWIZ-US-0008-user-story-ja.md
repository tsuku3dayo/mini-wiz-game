# US-0008 宿屋で休む

- エピック：[MWIZ-EP-0002](MWIZ-EP-0002-epic-ja.md)（キャラクターを作り、宿屋を拠点に遊ぶ）
- 優先順位：8 / 38（段階 2）

## ストーリー

**プレイヤーとして**、宿屋で休んで HP と MP を回復したい。**次の冒険に万全の状態で出られる** ようにするため。

## 受け入れ条件

- [ ] 宿屋の画面に、ステータス（full）・メニュー（やすむ／メニュー／ダンジョンへ／セーブ／タイトルへ戻る。v1.1 で並びを変えた）・メッセージ欄が出る（§11.5）
- [ ] やすむ で HP・MP が装備込みの最大値になり、最大のときも実行できる。メッセージ「HP と MP が かいふくした」（§7.2、§16.1）
- [ ] 費用はなく、何度でも使える。経験値・装備・所持品・実績は変わらない（§7.2）
- [ ] 経験値が次のレベル以上たまっていれば、やすむ でレベルが上がる。メッセージは「HP と MP が かいふくした」に続けてレベルアップの 2 行 × 上がった数で、上がった分の HP・MP も満タン。たまっていなければ乱数を使わない（§2.3、§7.2、§16.1。v1.1）
- [ ] 宿屋に戻っただけでは回復しない（§7.3）

## 確かめ方

自動（単体テスト・E2E）。
