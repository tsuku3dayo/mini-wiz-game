# US-0018 敵と遭遇する

- エピック：[MWIZ-EP-0004](MWIZ-EP-0004-epic-ja.md)（敵と戦い、強くなる）
- 優先順位：18 / 38（段階 4）

## ストーリー

**プレイヤーとして**、迷宮を歩いていると敵に出会ってほしい。階が深いほど強い敵に出会ってほしい。**緊張感のある探索ができる** ようにするため。

## 受け入れ条件

- [ ] 別のマスへ移動するたびに 20% で遭遇する。回転・壁・階段への到着・帰還では乱数を引かず遭遇しない。階段・入口のマスへ歩いて入っても遭遇しない（§16.2）
- [ ] 固定シード 10,000 回で遭遇率 18〜22%、各階の敵の比率が表 ±2.5 ポイント（§16.1、§16.2）
- [ ] 遭遇すると、メッセージ欄が消えてから「〇〇が あらわれた！」が出て、戦闘画面になる（§16.4）
- [ ] 敵 6 種の能力値・経験値・出現する階が §6.1 の表のとおり（§6）
- [ ] `SeededRng(1)` の `int(1,100)` 10 回が 63, 1, 53, 99, 97, 29, 62, 73, 43, 100（§16.1）
- [ ] `chance(0.1)` は `int`=10 で真、11 で偽。`chance` は乱数を 1 個だけ消費する（§16.1）

## 確かめ方

自動（単体テスト・E2E）。
