# US-0020 にげる

- エピック：[MWIZ-EP-0004](MWIZ-EP-0004-epic-ja.md)（敵と戦い、強くなる）
- 優先順位：20 / 38（段階 4）

## ストーリー

**プレイヤーとして**、勝てそうにない敵からは逃げたい。**無理をせずに生き延びられる** ようにするため。

## 受け入れ条件

- [ ] `fleeChance(5,5)=50`、`(13,5)=90`、`(14,5)=90`、`(5,13)=10`、`(5,14)=10`（§16.1）
- [ ] 逃走に成功すると「うまく にげきれた」で同じマスのダンジョンに戻る。経験値・ドロップはない（§5.3）
- [ ] 逃走に失敗すると、プレイヤーが速くても敵だけが攻撃する（§16.1）
- [ ] ボス戦で `flee` を送ると 409「にげられない！」。状態が変わらず乱数を消費しない（§16.1）

## 確かめ方

自動（単体テスト・E2E）。
