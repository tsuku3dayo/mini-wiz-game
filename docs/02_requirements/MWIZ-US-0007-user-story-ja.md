# US-0007 名前を付けてキャラクターを作る

- エピック：[MWIZ-EP-0002](MWIZ-EP-0002-epic-ja.md)（キャラクターを作り、宿屋を拠点に遊ぶ）
- 優先順位：7 / 38（段階 2）

## ストーリー

**プレイヤーとして**、自分のキャラクターに名前を付けて冒険を始めたい。**自分の分身として愛着を持って遊べる** ようにするため。

## 受け入れ条件

- [ ] 名前 `" ゆうしゃ　"` で作成すると名前は `"ゆうしゃ"`、Lv1・経験値 0・HP 30/30・MP 10/10・こうげき 5・ぼうぎょ 5・すばやさ 5・場所 INN・実績 `{0,0,0,1,0}` になる（§16.1）
- [ ] 名前が空・空白のみなら 400 で「名前を入力してください」、9 文字なら「名前は1〜8文字で入力してください」、`"ゆうしゃ😀"` なら「つかえない もじが ふくまれています」（§16.1）
- [ ] `"𠮷𠮷𠮷𠮷𠮷𠮷𠮷𠮷"`（8 文字）は作成でき、9 文字は作成できない（§16.1）
- [ ] 名前入力：空・9 文字以上・記号を含む名前では「決定」が無効になり、規則の文がエラーに出る。IME 変換中の Enter で送らない。Esc でタイトルへ戻る（§16.4）
- [ ] 作成すると「{名前}の ぼうけんが はじまった」と出て、宿屋に移る。セーブには触れない（§2.1、§21.6）
- [ ] スマートフォンでソフトウェアキーボードが出ても、画面が崩れない（§11.5）

## 確かめ方

名前の規則と初期値は自動（単体テスト）。画面は自動（E2E）。ソフトウェアキーボードは実機で手動。
