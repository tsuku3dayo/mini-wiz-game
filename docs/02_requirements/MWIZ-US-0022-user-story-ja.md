# US-0022 敵を倒して強くなる

- エピック：[MWIZ-EP-0004](MWIZ-EP-0004-epic-ja.md)（敵と戦い、強くなる）
- 優先順位：22 / 38（段階 4）

## ストーリー

**プレイヤーとして**、敵を倒して経験値を得て、レベルを上げたい。**キャラクターが育っていく楽しさを味わえる** ようにするため。

## 受け入れ条件

- [ ] 勝利すると「〇〇を たおした！」「経験値 n を かくとく」と出て、場所 DUNGEON・同じマス・経験値が加わり、HP は回復しない（§5.5、§16.1）
- [ ] `expForLevel` が Lv2：24、Lv3：72、Lv4：144、Lv5：240、Lv10：1,080、Lv100：118,800（§16.1）
- [ ] 経験値 0 に 23 を加えても Lv1 のままで乱数を消費しない。24 で Lv2 になり乱数をちょうど 5 個消費する（§16.1）
- [ ] 経験値 0 に 72 を加えると Lv3、メッセージ 4 行、成長最小（8,2,1,1,1 × 2）なら最大 HP 46（§16.1）
- [ ] 成長の乱数は maxHp → maxMp → attack → defense → speed の順に引かれる（§16.1）
- [ ] レベルアップで現在の HP・MP は増えた最大値の分だけ増え、全回復しない（§16.1）
- [ ] 固定シードで 10,000 回レベルアップすると、成長値は HP 8〜12・MP 2〜4・攻防速 1〜2 に収まり、両端が出る（§16.1）
- [ ] 戦闘で勝ったとき、メッセージを読み終えるまで戦闘画面に留まり、読み終えたらダンジョンへ移る（§16.4）
- [ ] ステータスに Lv・EXP（つぎまで）・HP・MP などが §11.6 の形で出る（§11.6）

## 確かめ方

自動（単体テスト・E2E）。
