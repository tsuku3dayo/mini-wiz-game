# US-0033 戦闘で敵の絵を見る

- エピック：[MWIZ-EP-0008](MWIZ-EP-0008-epic-ja.md)（敵の姿を見る）
- 優先順位：33 / 38（段階 8）

## ストーリー

**プレイヤーとして**、戦闘のときに敵の姿を絵で見たい。**どんな敵と戦っているのかが分かり、雰囲気を味わえる** ようにするため。

## 受け入れ条件

- [ ] 戦闘画面で、敵の名前の上にその敵の絵が出る（6 体すべて）（§16.5）
- [ ] どの画面の大きさでも 256px で出て、ぼやけない（§16.5）
- [ ] 画像の alt は敵の名前（§16.5）
- [ ] 画像が読めないとき、枠ごと消えて名前だけが出る（エラーにならない）（§16.5）
- [ ] 6 枚とも 256×256・背景透過で、MD5 が §13.1 と同じ。`enemy-images.test.ts` が通る（§16.5）

## 確かめ方

自動（単体テスト・E2E）。絵はオーナーが持ち込む（§13.3）。
