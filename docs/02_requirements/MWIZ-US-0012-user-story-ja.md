# US-0012 できない操作・保存の失敗が分かる

- エピック：[MWIZ-EP-0002](MWIZ-EP-0002-epic-ja.md)（キャラクターを作り、宿屋を拠点に遊ぶ）
- 優先順位：12 / 38（段階 2）

## ストーリー

**プレイヤーとして**、いまできない操作をしたときや、記録を保存できないときに、そのことを知りたい。**状態が壊れず、どうすればよいか分かる** ようにするため。

## 受け入れ条件

- [ ] 場所に合わない操作は 409 `invalid_state` で、状態は変わらない（§16.2）
- [ ] 操作の途中でほかのタブが先に書いていたら（revision が変わっていたら）409 `conflict` で、状態は変わらない（§16.2）
- [ ] ゲーム API のすべてのエラーが `GameError`（`{ status, error, message, details? }`）の形（§16.2）
- [ ] 端末内保存に書けないとき、操作は 500 `storage_error` になり、保存の中身は変わらない（§16.2）
- [ ] 端末内保存に書けない・続けられないエラーのとき、メッセージ欄の位置に「きろくを よみかき できません」と「再試行」が出る（§16.4）
- [ ] 保存の値が壊れていても起動でき、プレイ中のゲームなし（タイトル）として扱う（§16.2）

## 確かめ方

自動（単体テスト：偽の保存で書き込みを失敗させる、E2E）。
