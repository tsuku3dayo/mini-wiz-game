# US-0014 迷宮を一人称で歩く

- エピック：[MWIZ-EP-0003](MWIZ-EP-0003-epic-ja.md)（迷宮を探索する）
- 優先順位：14 / 38（段階 3）

## ストーリー

**プレイヤーとして**、一人称の疑似3D の視界を見ながら、ボタンやキーで迷宮を歩きたい。**昔ながらの迷宮探索の雰囲気を味わえる** ようにするため。

## 受け入れ条件

- [ ] 前進・後退は向きを変えず、回転は位置を変えない。壁では「かべだ」と出て動かない（§16.2）
- [ ] 移動ボタン（↑ 前進・← 左・右 →・↓ 後退）をタップ・クリックで押して動ける（§11.5）
- [ ] ダンジョンで矢印キーがページのどこからでも効き、ページはスクロールしない。応答待ち・逐次表示中・メニュー表示中の入力は捨てられる（§16.4）
- [ ] 疑似3D の線が §11.5（ダンジョン）の座標で描かれ、壁にぶつかると段 0 の正面の壁が 200ms 点滅する（§16.4）
- [ ] 視界は最大 4 段、正面の壁で止まり、視界外のマスを変えても結果が同じ。キーは floor・facing・underfoot・depths のみ（§16.2）
- [ ] 疑似3D の上に「{階}F　{向き}」（例：「3F　北」）が出る。座標は出さない（§4.8）

## 確かめ方

視界・線分は自動（単体テスト）。画面は自動（E2E）。
