# EP-0006 装備を集めて強くする

## 目的

敵が落とす装備（32 種・レアリティ 5 段階）を集め、付け替えて能力値を上げ、所持品を整理し、満杯のときは入れ替えられるようにする。

## 範囲

- 装備のマスタ・レアリティ・補正値・ドロップの抽選と行
- 所持品（50 個）・付け替え・はずす・捨てる・実効値・HP/MP の切り詰め
- 装備画面・もちもの画面・入れ替えの画面、並び順（強い順・弱い順）・しぼりこみ・変化の表示
- GameMenu の そうび・もちもの、セーブとの関係、古いデータの補正

含めないもの：rareDrop の演出と効果音（EP-0007）。
