# US-0024 ボスを倒してクリアする

- エピック：[MWIZ-EP-0005](MWIZ-EP-0005-epic-ja.md)（ボスを倒し、周回して記録を残す）
- 優先順位：24 / 38（段階 5）

## ストーリー

**プレイヤーとして**、5F の最奥にいる暗黒のネクロマンサーを倒してクリアしたい。**冒険の目標を達成した満足感を味わえる** ようにするため。

## 受け入れ条件

- [ ] 5F のボスのマスに入ると乱数を引かずに必ずボス戦になる（§16.2）
- [ ] ボスの経験値は 1000。Lv12・累計 1,584 で撃破すると累計 2,584 で Lv12 のまま。宿屋で やすむ と Lv15 になる（§16.1。v1.1）
- [ ] ボス撃破のメッセージは「たおした → 経験値 1000 → ドロップ → ダンジョンに 平和が もどった」の順で、場所 CLEARED（§16.1。v1.1 でレベルアップの行がなくなった）
- [ ] CLEARED になった操作で、最後に使ったスロット（なければ 1→3 の最初の空き）がクリア時点のキャラクター・所持品・実績で上書きされている。空きもなければ自動セーブしない（§9.2、§16.1。v1.1）
- [ ] ボス撃破（または撃破後の入れ替え）で CLEARED になったとき、プレイ中状態とセーブがまとめて書かれる。どちらかが書けなければ、両方とも書く前の値に戻る（§16.2）
- [ ] クリア画面に「暗黒のネクロマンサーを たおした」「暗黒のネクロマンサーは ほろび、ダンジョンに 平和が もどった」「{名前} Lv{レベル}」「ぼうけんの きろくを セーブした」（自動セーブしなかったときは「スロットが いっぱいなので セーブしなかった」）「{周回数} 周目へ すすむ」が出る（§11.5。v1.1）
- [ ] 平均成長・装備なしの Lv45 は、シード 1〜200 の模擬戦でボスに勝つ割合が 20% 以下。weapon7［SR］（+26）・armor7［SR］（+22）・shield7［SR］（かいひ +14）・accessory7［SR］（ドラゴンハート こうげき +21）を装備した Lv38 は 80% 以上勝ち、同じ装備の Lv32 は 20% 以下（§16.1。v1.3：ボスに勝てる目安を Lv35〜40 位にした。仕様書 v1.21、オーナーの決定。v1.2 は accessory4［R］（さいだいHP +15）を含む段階 7 の装備の Lv25 で 80% 以上・Lv21 で 20% 以下・装備なしの Lv27 で 20% 以下。v1.1 までは段階 5 の装備の Lv11 で 80% 以上・装備なしの Lv12 で 20% 以下）

## 確かめ方

自動（単体テスト：通しプレイ・模擬戦、E2E：クリア画面）。
