# US-0024 ボスを倒してクリアする

- エピック：[MWIZ-EP-0005](MWIZ-EP-0005-epic-ja.md)（ボスを倒し、周回して記録を残す）
- 優先順位：24 / 38（段階 5）

## ストーリー

**プレイヤーとして**、5F の最奥にいる暗黒のネクロマンサーを倒してクリアしたい。**冒険の目標を達成した満足感を味わえる** ようにするため。

## 受け入れ条件

- [ ] 5F のボスのマスに入ると乱数を引かずに必ずボス戦になる（§16.2）
- [ ] ボスの経験値は 1000。Lv12・累計 1,584 で撃破すると累計 2,584・Lv15 になる（§16.1）
- [ ] ボス撃破のメッセージは「たおした → 経験値 1000 → レベルアップ → ドロップ → ダンジョンに 平和が もどった」の順で、場所 CLEARED（§16.1）
- [ ] CLEARED になった操作で、セーブスロットがクリア時点のキャラクター・所持品・実績で上書きされている（§16.1）
- [ ] ボス撃破（または撃破後の入れ替え）で CLEARED になったとき、プレイ中状態とセーブがまとめて書かれる。どちらかが書けなければ、両方とも書く前の値に戻る（§16.2）
- [ ] クリア画面に「暗黒のネクロマンサーを たおした」「暗黒のネクロマンサーは ほろび、ダンジョンに 平和が もどった」「{名前} Lv{レベル}」「ぼうけんの きろくを セーブした」「{周回数} 周目へ すすむ」が出る（§11.5）
- [ ] 平均成長・装備なしの Lv12 は、シード 1〜200 の模擬戦でボスに勝つ割合が 20% 以下。weapon5（+11）・armor5（+9）・shield5（+6）・accessory4（さいだいHP +15）を装備した Lv10 は 80% 以上勝つ（§16.1）

## 確かめ方

自動（単体テスト：通しプレイ・模擬戦、E2E：クリア画面）。
