# AC-0007 タイトル・名前入力・宿屋の画面 の実施記録

## 1. 実施概要

| 項目 | 内容 |
| --- | --- |
| タスク | [TASK-0007](../06_plan/MWIZ-TASK-0007-implementation-task-ja.md) タイトル・名前入力・宿屋の画面 |
| 実施者 | Claude Code（オーナー：tsuku3dayo） |
| ブランチ | `feat/TASK-0007-title-inn` |
| 環境 | Windows 11・PowerShell、Node.js v24.0.0。Playwright 1.64.1 の Chromium |

作ったもの：

- `ui/screens/title.ts`：メニュー（はじめから／つづきから／おと）。セーブがあれば「つづきから」にカーソルと「{名前} Lv{n}」、なければ無効で、選んでも何も出さない。読み込み中はメニューを描かない。エラーのときはメニューを無効にし、下に ErrorPanel。メッセージ欄はない
- `ui/screens/name-entry.ts`：入力欄（文字数・規則の文）・もどる／決定・メッセージ欄。無効の「決定」を選ぶと理由をメッセージ欄に出す。Enter（変換中でなければ）で決定、Esc でもどる。ゲーム API の 400 は入力欄のエラー、500 はメッセージ欄の場所に ErrorPanel（「再試行」は名前の送信をやり直す）
- `ui/screens/inn.ts`：狭い画面は ステータス → メッセージ欄 → 操作の場所、広い画面は 2 段 × 2 カラム（段ごとに高さをそろえる）。操作の場所は 宿屋のメニュー／メニュー（GameMenu）／タイトルへ戻るの確認 を差し替える。やすむ・セーブ・タイトルへ戻る（はい で `quitGame` → メッセージを消してタイトルへ）。続けられないエラーはメッセージ欄の場所に ErrorPanel
- `main.ts`：名前入力・宿屋をルーターに登録
- `e2e/helpers.ts`：`startAt`（場所の状態とセーブを書いて画面を待つ。今は INN だけ）、メッセージ欄の行・メニューの項目・カーソルの行を読む関数

まだつないでいないもの（項目は出すが、選んでも何もしない）：

- 宿屋の「ダンジョンへ」（TASK-0009）、メニューの そうび・もちもの（TASK-0010 以降）・ステータス（TASK-0013）、タイトルとメニューの「おと」（TASK-0017）
- 広い画面の宿屋の右上（実績のウィンドウ）は空けてある（TASK-0013）

前の TASK の部品の直し：

- `components/command-menu.ts`：行がフォーカスを受けたときに行の要素を全部作り直していたため、カーソルのない行をクリック・タップしても決まらなかった（押し始めでフォーカスが移り、押し終わりが別の要素になる）。カーソルの移動と、無効・有効の切り替えでは行を作り直さず、印・色・tabindex だけを書き替えるようにした
- `ui/router.ts`：ハッシュなし（`#` だけを含む）で開いたときも `#/` に置き換える（TC-0006-06）

設計の直し：

- TD-0004 v1.1：宿屋の続けられないエラーは、操作の場所ではなく **メッセージ欄の場所** に ErrorPanel を出す（仕様書 §11.5、TC-0012-06 に合わせた）。参照する成果物 30 個の版の表記を直した

## 3. 確認できなかったこと

- Android の実機はないので、ソフトウェアキーボードの確認は iPhone 11 だけ（E2E の 414 × 400 で代わりに確かめた。TC-0007-10）。
- 「ダンジョンへ」・メニューの そうび／もちもの／ステータス／おと・タイトルの「おと」は、まだ何もしない（それぞれの TASK でつなぐ）。
- 宿屋の続けられないエラー（メッセージ欄の場所の ErrorPanel）は作ったが、確認 ID（TC-0012-06）は TASK-0011 の担当なので、E2E はまだない。
- 名前入力の `maxLength=8` は UTF-16 の数で止めるので、「𠮷」のような文字は 4 つまでしか手で打てない（規則は 8 文字まで可）。前から分かっている小さな食い違いで、直すかはオーナーに相談する。
