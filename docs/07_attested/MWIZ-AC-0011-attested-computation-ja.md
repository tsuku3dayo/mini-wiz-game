作ったもの：

- `ui/screens/battle.ts`：狭い画面（敵のウィンドウ → メッセージ欄 5 行 → ステータス → 見出し「コマンド」のメニュー）、広い画面（敵のウィンドウ、下を 2 カラム：メッセージ欄 7 行｜ステータス・コマンド）。コマンドは たたかう／ヒール（MP 不足で無効「MP が たりない」）／にげる（ボス戦で無効「にげられない！」）。場所が BATTLE でない・応答待ち・逐次表示中はメニュー全体を無効。勝利・死亡の表示中は直前の敵を出し続ける。敵の名前はボスなら赤
- ダメージの点滅：新しく出た行に「ダメージを うけた」があると、ステータスの HP の値を 200ms 点滅（`status-panel` の `setFlash`）
- 体力わずかの赤い枠：`components/low-hp-frame.ts`（HP × 5 ≦ 最大HP の間、`#app` に `data-low-hp` と `--wiz-window-line` の赤）
- 遭遇の判定を `logic/arrival.ts` の `isEncounter` にし、`command` から使う（遭遇でメッセージ欄を消す）
- ダンジョンのメニューの「ヒール」を `heal` につないだ（使ってもメニューは開いたまま）
- `e2e/helpers.ts`：`startAt('BATTLE', …)`（既定はゴブリン HP 18）・`battleOf`、シード `SEEDS.slimeNext`（7：次の一歩でスライム）・`SEEDS.hits`（1：最初の攻撃が当たる・逃走 90% が成功・ドロップしない）。`startAt` はどの場所でもシードを入れる（既定は遭遇しない 11350）

テストケースの直し：

- TC-0011 v1.1：TC-0011-03 の戦闘の場面。戦闘の行は長く、狭い画面でも desktop でも 2 行に折り返すので、欄にちょうど 5 行・7 行は並ばない（仕様書どおり、入りきらない古い行は消える）。「行の数は最大以下で、最新の行が出て、欄の高さを超えない」に直した。参照する成果物の版の表記を直した（承認済みの AC-0006・0009 は表記だけ）

前の TASK のテストの名前の直し：

- `e2e/debug.spec.ts` の TC-0038-04（TASK-0009）・`e2e/menu.spec.ts` の TC-0010-10（TASK-0007）・`e2e/boot.spec.ts` の TC-0001-05（TASK-0003）で、確認 ID と文の間の空白が抜けていた。TC-0038-04 は後ろが英字（useSeed）で区切りがなく、check:docs が数えていなかった（この TASK で数えが 1 つ合わないことから見つけた）。3 つとも空白を戻した
