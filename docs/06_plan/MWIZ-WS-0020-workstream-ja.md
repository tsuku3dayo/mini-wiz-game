# WS-0020 かいひ を すばやさ＋たて に・スマートフォンの戦闘のボタンを大きく

- 実施の順：20 / 20（完了のあとの変更の依頼 `docs/requests/2026-11-11-spec-1.16-evasion-battle-buttons.md` の修正用の WS）
- ユーザーストーリー：US-0019・US-0026・US-0028・US-0035

## 目的

仕様書 v1.16 の 2 つの変更を入れる。

1. かいひ ＝ すばやさ（装備込み）＋ たて、敵の かいひ ＝ 敵のすばやさ、回避率 ＝ かいひ − 攻撃側のすばやさ（計算の結果は v1.14 と同じ）。かいひ の行に ` (+n)`
2. スマートフォンの戦闘のコマンドを、枠なし・高さ 88px のボタンに

- 変更が小さく、どちらも戦闘の画面・ステータスの表示に触れるので、1 つの TASK にまとめる。
- 戦闘のボタンの形は、04 で CSS を当てて仮に作り、測ってある（TD-0004 v1.7：画面の高さ 634px、375 × 667・414 × 715 で収まる）。

## WS の終わりの手動テスト

実機（iPhone 11・PC）で次を確かめ、AC-0038 に結果を書く。

- 宿屋・ステータス画面の「かいひ」が すばやさ＋たて で、たて を付けると「 (+n)」が付く
- 装備画面の のうりょく の かいひ の行（たて・ウィンドブーツの候補で変わる）
- 戦闘のボタン（iPhone）：枠がなく、88px で親指で押しやすいか
- 戦闘の回避の感じ（いままでと変わらないこと）

進め方：

- TASK-0038 を公開したら、すぐに案内する（更新の帯が出たら押す・開き直す）。返事のひな形を付ける。
- Android の実機はないので、AC の「確認できなかったこと」に書く（E2E の `pixel7` で代わりに確かめる）。
