# WS-0013 BGM と効果音の入れ替え

- 実施の順：13 / 13（完了のあとの変更の依頼 `docs/requests/2026-11-06-spec-1.7-bgm.md` の修正用の WS）
- ユーザーストーリー：US-0032（効果音）、US-0034（BGM）

## 目的

BGM を、著作権の切れたクラシックの名曲・民謡の編曲 6 曲に入れ替え、ボス撃破のあと宿屋に戻るまでクリアの曲を流す。効果音を、ビープ音風から暗い FM 音源風に入れ替える（長さは同じ）。どれもオーナーが試聴ページで選んだもの（仕様書 v1.7）。

## TASK（確認 ID 14 個）

| TASK | 内容 | 確認 ID の数 | ブランチ |
| --- | --- | --- | --- |
| [TASK-0029](MWIZ-TASK-0029-implementation-task-ja.md) | BGM と効果音の入れ替え | 14 | `feat/TASK-0029-bgm-se` |

- 曲と効果音は、試聴ページで鳴らしたものと同じ値を、仕様書 §25.2・§26.9 のコード（正本）から写す。曲ごとに TASK を分けない（曲データは 1 つのファイルで、試聴で全部決まっているため）。

## WS の終わりの手動テスト

実機（iPhone 11・PC）で次の確認 ID を行い、AC-0029 に結果を書く：TC-0032-20（効果音を聴く）、TC-0034-04（6 曲が途切れずにつながる）、TC-0034-18（効果音のあいだ曲が小さくなる）、TC-0034-23（6 曲の印象）。

- 案内はマージ（公開）の前に渡す。すでに遊んでいる端末では、更新の帯が出たら押す（または開き直す）と新しい音になることも伝える。
- 返事のひな形には、聴いた曲・効果音の名前を書く欄を付ける（SDD-PROCESS §4.4）。ボス戦・クリア・LG のドロップなど、すぐ行けない場面は `?debug=1` の場面で作る手順を、手元で動かしてから渡す。
- Android の実機はないので、Android での確認は AC の「確認できなかったこと」に書く。
