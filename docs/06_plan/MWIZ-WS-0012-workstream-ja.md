# WS-0012 タイトル画像と敵の絵の v2 への差し替え

- 実施の順：12 / 12（完了のあとの変更の依頼 `docs/requests/2026-11-06-spec-1.4-images-v2.md`・`docs/requests/2026-11-06-spec-1.5-enemy-images-256.md` の修正用の WS）
- ユーザーストーリー：US-0006（タイトル画面）、US-0033（戦闘で敵の絵を見る）

## 目的

タイトル画像と敵の絵 6 枚を、オーナーが用意した v2 の絵に差し替える。

- v1.4：タイトル画像と、128×128 の敵の絵（画面では 2 倍の 256px）に替えた（TASK-0026）。
- v1.5：敵の絵を、同じ絵柄の 256×256 の絵に替え、拡大せずに 256px で出す（TASK-0027。v1.1 で足した）。

## TASK（確認 ID 13 個。重なりを除くと 9 個）

| TASK | 内容 | 確認 ID の数 | ブランチ |
| --- | --- | --- | --- |
| [TASK-0026](MWIZ-TASK-0026-implementation-task-ja.md) | タイトル画像と敵の絵の v2 への差し替え（v1.4） | 8 | `feat/TASK-0026-images-v2` |
| [TASK-0027](MWIZ-TASK-0027-implementation-task-ja.md) | 敵の絵の 256×256 の v2 への差し替え（v1.5） | 5 | `feat/TASK-0027-enemy-images-256` |

- TASK-0027 の確認 ID は、TASK-0026 の敵の絵の確認 ID（TC-0033-01・02・05・06）を 256×256 の絵でもう一度行うもの（と、`e2e/pwa.spec.ts` の敵の絵の読み込みの確かめ）。

## WS の終わりの手動テスト

実機（iPhone 11・PC）で次の確認 ID を行う：

- TC-0006-13（タイトル画像の見え方）：AC-0026 に書く。2026-11-06 にオーナーが確かめた（PC・iPhone で OK）。
- TC-0033-06（敵の絵の見え方）：AC-0027 に書く。v1.4 の 128×128 の絵は、実機で見る前に v1.5 で替えることになったので、256×256 の絵で確かめる（AC-0026 には、そう書く）。

- 案内はマージ（公開）の前に渡す。すでに遊んでいる端末では、更新の帯が出たら押す（または開き直す）と新しい絵になることも伝える。
- TC-0006-13 の「セーブのある状態でも見る」は、画像を替えただけでタイトル画面の作りは変えないので、今回は頼まない（理由を案内と AC に書く。SDD-PROCESS §4.4）。
- Android の実機はないので、Android での確認は AC の「確認できなかったこと」に書く（E2E の `pixel7` で代わりに確かめる）。
