# WS-0023 難易度の調整（ボスに勝てる目安を Lv25 位に）

- 実施の順：23 / 23（完了のあとの変更の依頼 `docs/requests/2026-11-12-spec-1.20-difficulty.md` の修正用の WS）
- ユーザーストーリー：US-0018・US-0024・US-0025

## 目的

仕様書 v1.20 の変更を入れる：スライム以外の敵とボスの能力値、スケルトン・オークロード・ダークナイトの経験値を改め（§6.1）、ボスの釣り合いの基準（§16.1）を「良い装備の Lv25 で 80% 以上・同じ装備の Lv21 で 20% 以下・装備なしの Lv27 で 20% 以下」にする。

## TASK（確認 ID 7 個）

| TASK | 内容 | 確認 ID の数 | ブランチ |
| --- | --- | --- | --- |
| [TASK-0041](MWIZ-TASK-0041-implementation-task-ja.md) | 敵の数字と釣り合いのテスト | 7（直す 7） | `feat/TASK-0041-difficulty` |

- 変えるのは定数（`ENEMIES`）だけで、ルールの関数は変えない。数字に頼るテストの手直しが中心なので、1 つの TASK にまとめる。
- 04 の時点で、新しい数字を仮に当てて単体テストを全部動かし、落ちる 11 件（下の TASK の表）と、通しプレイ（TC-0024-05・TC-0025-03）が新しい数字でも最後まで遊べることを確かめてある（2026-11-12）。

## WS の終わりの手動テスト

実機（iPhone 11・PC）で次を確かめ、AC-0041 に結果を書く。

- 1F から遊んで、各階の敵の手ごたえ（1F は Lv1 から遊べる。4F・5F は急に強く感じすぎないか）
- 遊ぶ長さ（待たされすぎ・稼ぎが退屈すぎないか）
- できれば、Lv25 前後でボスに挑んだときの手ごたえ（PC は `?debug=1` のコンソールで、良い装備の Lv25 のボスの手前の場面を作ってよい）

進め方：

- TASK-0041 を公開したら、すぐに案内する（更新の帯が出たら押す・開き直す）。返事のひな形を付ける。案内の項目は、この節の文から写す。
- 1F から Lv25 まで遊ぶのは時間がかかるので、確かめる範囲（どこまで遊んだか）を返事に書いてもらい、AC にそのまま書く。
- Android の実機はないので、AC の「確認できなかったこと」に書く。
