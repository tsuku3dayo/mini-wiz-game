# WS-0024 敵と装備に特徴をつける（ボスに勝てる目安を Lv35〜40 位に）

- 実施の順：24 / 24（完了のあとの変更の依頼 `docs/requests/2026-11-13-spec-1.21-enemy-equipment-features.md` の修正用の WS）
- ユーザーストーリー：US-0009・US-0018・US-0024・US-0027・US-0028

## 目的

仕様書 v1.21 の変更を入れる：敵の能力値とボス以外の経験値（§6.1）、装備のマスタ・補正値の決め方（レアリティごとの範囲。§8.2・§8.3）、アクセの並びと能力（ウィンドブーツは かいひ、ソロモンのゆびわは 3 つ）、保存の版（7・4）とアクセの ID の付け替え（§21.4）、ボスの釣り合いの基準（§16.1）。

## TASK

- アクセの並びを変える作りと、セーブのアクセを付け替える作りは、同じ公開に入れないと、公開のあいだに読み込んだセーブのアクセが別の種類に変わる。敵の数字と釣り合いのテストも、装備の範囲で結果が変わるので、1 つの TASK にまとめる。
- 04 の時点で、新しい仕様を仮に当てて単体テストと E2E を全部動かし、落ちるテスト（TASK の表）を確かめてある（2026-11-13）。仮に当てたコードの差分は、作業用の一時フォルダに残した（TASK で使う）。

## WS の終わりの手動テスト

実機（iPhone 11・PC）で次を確かめ、AC-0042 に結果を書く。v1.20 の確認（WS-0023）もここにまとめた（依頼書 §2 の 4）。

- 1F から遊んで、各階の敵の手ごたえ（スライムの しぶとさ、スケルトンの速さと痛さ、オークロードの HP の多さなど、敵ごとの特徴が感じられるか。急に強く感じすぎる階がないか）
- 遊ぶ長さ（とくに 5F で Lv21 前後から Lv35〜38 まで育つあいだ、待たされすぎ・稼ぎが退屈すぎないか）
- 装備（拾える装備の強さの差が分かるか。ソロモンのゆびわの補正 3 つが、装備画面・もちもの・ドロップの行で読めるか）
- できれば、Lv35〜40 でボスに挑んだときの手ごたえ（PC は `?debug=1` のコンソールで、良い装備の Lv38 のボスの手前の場面を作ってよい）
- 今のセーブ（v1.20 で遊んでいたもの）を読み込んで、アクセの名前が変わらないこと（持っている人だけ）

進め方：

- TASK-0042 を公開したら、すぐに案内する（更新の帯が出たら押す・開き直す）。返事のひな形を付ける。案内の項目は、この節の文から写す。
- 1F から Lv35 以上まで遊ぶのは時間がかかるので、確かめる範囲（どこまで遊んだか）を返事に書いてもらい、AC にそのまま書く。
- Android の実機はないので、AC の「確認できなかったこと」に書く。
