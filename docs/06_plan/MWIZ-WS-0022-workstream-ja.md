# WS-0022 敵の絵を v5（背景は黒のまま）に差し替え、敵のウィンドウの中を真っ黒に

- 実施の順：22 / 22（完了のあとの変更の依頼 `docs/requests/2026-11-12-spec-1.19-enemy-images-v5.md` の修正用の WS）
- ユーザーストーリー：US-0033

## 目的

仕様書 v1.19 の変更を入れる。

1. 敵の絵 6 枚を v5 に差し替える（背景の真っ黒は透明にせず、付属の情報だけを取り除く。絵の点は変えない）
2. 戦闘の敵のウィンドウの中の背景を `#000000`（enemyBackground）にして、絵のまわりの四角を見せない

## TASK（確認 ID 3 個）

| TASK | 内容 | 確認 ID の数 | ブランチ |
| --- | --- | --- | --- |
| [TASK-0040](MWIZ-TASK-0040-implementation-task-ja.md) | 敵の絵の v5 への差し替えと、敵のウィンドウの背景 | 3（新しい 1・直す 2。うち手動 1） | `feat/TASK-0040-enemy-images-v5` |

- 絵と色の変更は小さく、どちらも戦闘の敵のウィンドウに触れるので、1 つの TASK にまとめる。
- 絵の置き方と、敵のウィンドウの背景は、依頼の時に仮に当てて撮り、測ってある（GUI-0005 v1.7・TD-0004 v1.9：四角が見えない、画面の高さは変わらない）。

## WS の終わりの手動テスト

実機（iPhone 11・PC）で次を確かめ、AC-0040 に結果を書く。

- 敵の絵（v5）がぼやけず、細かいところまで見える。絵のまわりに四角が見えない（TC-0033-06）
- 敵のウィンドウの中の黒と、ほかのウィンドウ・画面の背景の色の違いが気にならない

進め方：

- TASK-0040 を公開したら、すぐに案内する（更新の帯が出たら押す・開き直す）。返事のひな形を付ける。案内の項目は、この節の文から写す。
- Android の実機はないので、AC の「確認できなかったこと」に書く（E2E の `pixel7` で代わりに確かめる）。
