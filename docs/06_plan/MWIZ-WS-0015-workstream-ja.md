# WS-0015 タイトル・宿屋・ボス戦の BGM の入れ替え

- 実施の順：15 / 15（完了のあとの変更の依頼 `docs/requests/2026-11-09-spec-1.9-bgm-swap.md` の修正用の WS）
- ユーザーストーリー：US-0034（BGM）。WS-0013 の終わりの実機の確認（US-0032 の効果音を含む）を引き継ぐ

## 目的

タイトルの曲をカタコンベ（v1.8 までのボス戦の曲）に、宿屋の曲をローエングリン（v1.8 までのタイトルの曲）に、ボス戦の曲をモーツァルト『レクイエム』より「怒りの日」にする。どれもオーナーが試聴ページで選んだもの（仕様書 v1.9）。

- 曲データは、仕様書 §26.9 のコード（正本）から写す。曲の名前・場面の選び方・再生の仕組みは変えない（TD-0005 v1.10）。

## WS の終わりの手動テスト

実機（iPhone 11・PC）で次の確認 ID を行い、AC-0031 に結果を書く：TC-0032-20（効果音を聴く。WS-0013 から引き継ぎ）、TC-0034-04（6 曲が途切れずにつながる。ボス戦の曲が途切れない）、TC-0034-18（効果音のあいだ曲が小さくなる）、TC-0034-23（6 曲の印象）。

- WS-0013 の AC-0029 には「v1.9 で曲を入れ替えたので、実機の確認は AC-0031 に引き継いだ」と書き、AC-0031 と一緒に review にしてオーナーの承認を受ける（変更の依頼 v1.9 §2.2 の 6）。
- 案内はマージ（公開）の前に渡す。すでに遊んでいる端末では、更新の帯が出たら押す（または開き直す）と新しい曲になることも伝える。
- 返事のひな形には、聴いた曲・効果音の名前を書く欄を付ける（SDD-PROCESS §4.4）。ボス戦・クリアなど、すぐ行けない場面は `?debug=1` の場面で作る手順を、手元で動かしてから渡す。
- Android の実機はないので、Android での確認は AC の「確認できなかったこと」に書く。
