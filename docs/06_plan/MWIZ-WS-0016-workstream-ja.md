# WS-0016 効果音のジングル化

- 実施の順：16 / 16（完了のあとの変更の依頼 `docs/requests/2026-11-10-spec-1.10-se-jingle.md` の修正用の WS）
- ユーザーストーリー：US-0031（演出の長さ）・US-0032（効果音）。WS-0013・WS-0015 の効果音の実機の確認（TC-0032-20）を引き継ぐ

## 目的

遭遇・レベルアップ・ボス出現・ボス撃破・ゲームクリアの効果音を、オーナーがジングルの試聴ページで選んだ音にし、その 4 つの演出の長さを音の長さに合わせて延ばす（仕様書 v1.10）。

## WS の終わりの手動テスト

実機（iPhone 11・PC）で次の確認 ID を行い、AC-0032 に結果を書く：TC-0032-20（効果音を聴く。鳴り切るか、待たされる感じ）、TC-0034-18（効果音のあいだ曲が小さくなる。音が長くなったので、もう一度）。

- BGM の確認（TC-0034-04・TC-0034-23）は 2026-11-10 にオーナーが OK と答えた。AC-0031 に書き、効果音の確認（TC-0032-20）は「v1.10 で効果音を変えたので AC-0032 に引き継いだ」と書く。AC-0029 も同じ。AC-0029・AC-0031・AC-0032 を一緒に review にして承認を受ける（変更の依頼 v1.10 §2.2 の 5）。
- 案内はマージ（公開）の前に渡す。すでに遊んでいる端末では、更新の帯が出たら押す（または開き直す）と新しい音になることも伝える。
- 返事のひな形には、聴いた効果音の名前を書く欄を付ける（SDD-PROCESS §4.4）。ボス出現・ボス撃破・クリア・UR・LG は `?debug=1` の場面で作る手順を、手元で動かしてから渡す。
- ボス出現の文字が約 2.9 秒出たままになる見た目も、実機で見ていただく（変更の依頼 v1.10 §2.3）。
- Android の実機はないので、Android での確認は AC の「確認できなかったこと」に書く。
