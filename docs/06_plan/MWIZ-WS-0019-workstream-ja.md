# WS-0019 セーブ 3 つ・宿屋でのレベルアップ・盾の かいひ ほか

- 実施の順：19 / 19（完了のあとの変更の依頼 `docs/requests/2026-11-11-spec-1.14-slots-levelup-evade.md` の修正用の WS）
- ユーザーストーリー：US-0006・US-0008・US-0009・US-0019・US-0022・US-0024・US-0028・US-0035

## 目的

仕様書 v1.14 の 6 つの変更を入れる。

1. セーブ 3 スロット
2. レベルアップは宿屋の「やすむ」だけ
3. 宿屋のメニューの並び
4. 「オークロード」
5. たての「かいひ」と回避の式
6. スマートフォンの戦闘のボタン

- 順は **ルール → 画面 → セーブ**。依頼書 §2.7 の見込み（TASK-0036 がセーブ、TASK-0037 が画面）から入れ替えた。宿屋のセーブの一覧から戻ったときのカーソル（「セーブ」＝上から 4 つ目）が、宿屋の並びの変更に頼るためである。
- 通しの確認（タップだけ・キーだけで最後まで、読み上げの検査）は、全部の変更が入った TASK-0037 で直す。
- どの TASK も公開（main へのマージ）でゲームが変わる。TASK-0035 を公開してから TASK-0037 を公開するまでのあいだも、遊べる状態を保つ（ルールだけが先に変わる）。

## WS の終わりの手動テスト

実機（iPhone 11・PC）で次を確かめ、AC-0035〜0037 に結果を書く。

- **すでに遊んでいる端末のセーブが、スロット 1 に移ること**（TC-0004-04。オーナーの iPhone にはいまのセーブがある）
- 宿屋で やすむ とレベルが上がる（音・光る演出）
- たて の「かいひ」の表示
- 宿屋の並び
- 戦闘のボタン（親指で押しやすいか）
- セーブのスロットの一覧・上書きの確認
- タイトルの「つづきから」

進め方：

- 最後の TASK（TASK-0037）を公開したら、すぐに案内する（SDD-PROCESS §6：待っている確認を作らない）。更新の帯が出たら押す（または開き直す）と新しい版になることも伝える。TASK-0035 の公開のあとも、遊べることを短く伝える。
- 返事のひな形を付ける（iPhone・PC それぞれ「セーブがスロット 1 に移ったか」「やすむ でレベルが上がったか」「戦闘のボタンの押しやすさ」「セーブ・つづきからのスロットの選び方」）。
- Android の実機はないので、Android での確認は AC の「確認できなかったこと」に書く（E2E の `pixel7` で代わりに確かめる）。
