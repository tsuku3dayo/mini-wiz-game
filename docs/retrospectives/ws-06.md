## W（わかったこと）

- **読み上げ用の隠し文が、スクロールする一覧の外にはみ出していた。**
  - 何が起きたか：もちもの画面の一覧は、高さを決めて中をスクロールさせる。ところが、画面の写真を撮って測ると、ページ全体が 800px 以上も縦に伸びていた。
  - なぜ起きたか：隠し文は CSS の `position: absolute` で見えなくしている。この置き方の要素は、一覧ではなく、外のウィンドウを基準に置かれる。そのため、一覧のスクロールの枠で切られず、ページを伸ばしていた。E2E は要素や文字を確かめるので、この伸びには気づかなかった。
  - どうしたか：スクロールする一覧を `position: relative` にして、中の隠し文も枠で切るようにした（TD-0003 v1.2）。
- **はみ出しを 4 つの大きさで測ると、ほかにも 3 つ見つかった。**
  - 装備が多いと、一番小さいスマートフォン（375 × 667）で「のうりょく」が画面の下に出る。低い PC の画面（1366 × 657）で入れ替えの一覧が 104px はみ出す。iPhone 11 の大きさ（414 × 715）で、高さの端数のため 1px はみ出す。
  - 撮影用の一時のテストで、4 つの大きさの `scrollHeight − innerHeight`（ページの高さと画面の高さの差）を測って見つけた。PC と一番小さいスマートフォンの写真を見るだけでは、2 つは見落としていた。
- **テストケースの例の装備が、ゲームの決まりで直されてしまうものだった。**
  - 何が起きたか：TC-0028 の準備に「バトルアックス［SR］」とあった。この強さの段階の装備に［SR］は出ないので、保存を読み込むときに［R］に直される（TC-0029-10 の決まり）。
  - どうしたか：TASK-0014 で気づいて AC に書いておき、TASK-0015 の E2E では「ロングソード［SR］」にした。テストケースを書くとき、例の値がルールの決まりを満たすかを見ていなかった。
- **実機の確認で、更新の帯は「アプリを開き直したとき」にしか出ないことを、先に伝えていなかった。**
  - 何が起きたか：オーナーは、マージのあともアプリを開いたままにして、帯が出ないのを見た。開き直したら帯が出た。これは仕様どおりの動き（新しい版は、開いたときに確かめに行く）。
  - その結果：5 つの見ることのうち 3 つ（押すまで切り替わらない・切り替えのあとのプレイ中の状態・ダンジョンで帯が出ない）は見ていない。手順（宿屋でセーブ → ダンジョンを歩く → 開き直す…）を、マージの前に渡していなかったため。E2E では確かめてあるので、次の WS の最初のマージのときに、手順どおりもう一度確かめる。
- **テストの名前の確認 ID の後ろの空白が、また抜けていた。**
  - TASK-0014 で、前の TASK のテスト 3 つに見つけて直した。後ろが日本語の文字だったので、数え方には影響がなかった。前回の T（「テストのコードに N」の増え方を見る）では、増え方が合っていれば気づけない。
- **時間を測る単体テストが、手元でほかのテストと同時に動かしたときに 1 回ずつ失敗した。**
  - 迷宮を作る速さのテスト（TC-0013-06）と視界のテスト（TC-0014-06）。単独では通る。視界のテストは時間切れを 30 秒にした。作る速さは仕様の基準なので変えず、今回の TASK-0015 では起きなかった。

## T（つぎにやること）

- **スクロールする部品の中に `position: absolute` の要素（読み上げ用の隠し文など）を置くときは、スクロールする要素を `position: relative` にする。** 枠で切られず、ページが伸びるため。→ 手順書 §8「07 実装」に足す。
- **一覧・スクロールのある画面を作ったら、375 × 667・414 × 715・1280 × 800・1366 × 657 の 4 つで、はみ出し（`scrollHeight − innerHeight`）を測る。項目の多い場面（所持品 50 個など）でも測る。** 写真を見るだけでは、数 px のはみ出しや、項目が多いときのはみ出しを見落とすため。→ 手順書 §8「07 実装」に足す。
- **テストケースの準備に書く例の値（装備・敵・状態）が、ルールの決まり（段階で出るレアリティ・値の範囲など）を満たすかを確かめる。** 読み込みで直される値は、画面の文字が変わってしまうため。→ 手順書 §8「05 テスト」に足す。
- **実機の確認の手順は、マージ（公開）の前に、見ることの一覧と一緒にオーナーに渡す。PWA の更新では「帯は、アプリを開き直したときに出る」ことも先に伝える。** 公開のあとでは、手順の前半（セーブ・ダンジョンを歩く）をやり直せないため。→ 手順書 §4.4「WS の終わり」に足す。
