# GUI-0007 演出・エラー・更新の帯・インストールの案内・起動の失敗

## 1. 演出

仕様書 §11.8 のとおり（長さ・回数・色）。画面全体の層は `position: fixed; inset: 0`、`pointer-events: none`、`aria-hidden`。

| 演出 | 出す所 | ストーリー |
| --- | --- | --- |
| levelUp | ステータスが琥珀で 2 回光り、メッセージの行が 1.2 倍に（左端基準） | US-0031 |
| rareDrop | 画面の縁がレアリティの色で光り、行が点滅（UR 2 回・LG 3 回） | US-0031 |
| bossAppear | 画面全体が黒と血の赤で明滅し、中央に敵の名前（36px、折り返す） | US-0031 |
| bossDefeat | 画面全体が羊皮紙色で 2 回明るくなる | US-0031 |
| clear | クリア画面の見出しが下から浮かび上がる | US-0031 |
| 体力わずか | すべてのウィンドウの二重線が血の赤（`#FF5A4E`）。試作の「体力わずか」で確かめられる | US-0019 |

- 動きを減らす設定では、色の強調だけにして動かさない。明滅は 1 秒に 3 回以下。

## 2. 更新の帯

```
┌────────────────────────────────────┐
│ 新しい版があります          [更新] │  画面の上端に固定（安全領域の下）。下線はくすんだ金
├────────────────────────────────────┤
│ （タイトル・宿屋の画面）             │
```

- タイトル・宿屋の画面のときだけ出す。ほかの画面に移ったら隠す（US-0004）。
- 帯は画面の上に重なる。上端の内容（タイトルの飾り線・宿屋の画面名）が隠れるが、操作は下にあるので困らない（試作で確かめる）。

## 3. インストールの案内（ダイアログ）

```
┌─【 インストール 】─────────────────┐
│ ホーム画面に追加すると、アプリのように│
│ 開けます。通信がなくても遊べます。   │
│ ▼ iPhone（Safari）                  │  今の端末のものだけ最初から開く
│   画面下の共有ボタン →「ホーム画面に追加」│
│ ▶ Android（Chrome）                 │
│ ▶ パソコン（Chrome / Edge）         │
│        [今すぐインストール] [とじる] │  「今すぐインストール」はブラウザがすぐできるときだけ
└────────────────────────────────────┘
```

- タイトル画面の「インストール」で開く。`<dialog>` のモーダル（仕様書 §11.1 の例外）。「とじる」・Esc で閉じ、フォーカスを「インストール」に戻す（US-0002）。
- 二重線のウィンドウと同じ見た目。幅は画面の 92%（最大 480px）。

## 4. ErrorPanel（続けられないエラー）

メッセージ欄の場所に出す（宿屋なら、ステータスとコマンドの間）。タイトル画面にはメッセージ欄がない（GUI-0002 §1）ので、メニューの下に出す。

```
│ ┌─【 エラー 】────────────────────┐ │  外側の線が血の赤
│ │ きろくを よみかき できません     │ │  role="alert"
│ │ ▶再試行                         │ │
│ └─────────────────────────────────┘ │
```

- 「再試行」でゲームの状態を取り直す（US-0012）。

## 5. 起動の失敗

```
┌────────────────────────────────────┐
│                                    │
│      うまく起動できませんでした。    │
│            [ なおす ]               │  ボタンは琥珀、高さ 48 以上
│        きろくは消えません。          │
│                                    │
└────────────────────────────────────┘
```

- `public/boot.js` が出す（CSS が読めないときに備えて色をスクリプトに直接書く：背景 `#0B0A0F`、文字 `#E8DCC0`、枠 `#FFFFFF`、ボタン `#FFC845`）（US-0005）。
