# GUI-0004 ダンジョン画面（`#/dungeon`）

## 1. 画面の形

### 1.1 414 × 715（iPhone 11 の Safari）

```
┌────────────────────────────────────┐
│ 3F　北                              │  LocationLabel（h2 18px）。画面名「ダンジョン」は見た目で隠す
│      ╲                    ┌──┐     │
│       ┃╲──────────────╱┃  │  │     │  疑似3D（SVG、4:3）
│       ┃ ┃            ┃ ┃  │  │     │  幅 = min(320, 画面の幅, 高さに収まる幅)
│       ┃ ┃ ↓ くだり階段 ┃ ┃  │  │     │  → 414 × 715 で 288 × 216
│       ┃╱──────────────╲┃  └──┘     │
│      ╱                              │
│ ┌────────────────────────────────┐ │
│ │（メッセージ欄 5 行）             │ │
│ └────────────────────────────────┘ │  間は 8px だけ（GUI-0001 §2-1）
│ ┌────────────────────────────────┐ │
│ │ゆうしゃ Lv 12 HP120/135 MP 31/ 43│ │  ステータス（1 行。GUI-0001 §4.4）。メッセージ欄の下（戦闘と同じ）
│ └────────────────────────────────┘ │
│ ┌──────────┐ ┌───┐ ┌────┐ ┌───┐   │
│ │ 自動地図  │ │   │ │↑前進│ │   │   │  地図（160 × 160）と移動ボタンを横に並べる
│ │ 160×160  │ │← 左│ ├────┤ │右 →│   │  移動ボタンは右側（右手の親指）
│ │          │ │   │ │↓後退│ │   │   │  高さは地図に合わせる（ボタン 1 つ 80px 以上）
│ └──────────┘ └───┘ └────┘ └───┘   │
│ [↓ おりる]               [≡ メニュー]│  操作の行：左に階段・帰還、右にメニュー
└────────────────────────────────────┘
```

### 1.2 大きさの計算

| 画面（CSS px） | 疑似3D | 縦のはみ出し（試作で測った値） |
| --- | --- | --- |
| 414 × 715（iPhone 11 の Safari） | 288 × 216 | 0 |
| 414 × 814（iPhone 11 のホーム画面のアプリ） | 320 × 240 | 0 |
| 375 × 667（下限） | 224 × 168 | 0 |
| 412 × 839（Pixel 7） | 320 × 240 | 0 |
| 1280 × 800（PC） | 320 × 240 | 0 |

- 試作で測った値（2026-10-30。メッセージ欄 5 行）。メッセージ欄が 1 行ふえたので、狭い画面では疑似3D が 4 行のときより小さい（414 × 715 で 317 → 288）。
- 疑似3D の幅 = min(320, 使える幅, 画面に収まる高さ × 4/3)。最小 200px（それより狭くなるときは縦にスクロールする）。

### 1.3 広い画面（600px 以上。PC）

```
ダンジョン
3F　北
┌──────────────────────────────────────────┐ ┌────────┐
│                                          │ │ 自動地図│  地図は右上
│   疑似3D（地図の手前まで広げる。          │ │160×160 │
│          1280 × 800 で 596 × 447）        │ └────────┘
│                                          │
└──────────────────────────────────────────┘
┌─────────────────────────┐ ┌─【 ステータス 】──────────┐
│（メッセージ欄 5 行）     │ │ゆうしゃ Lv 12 HP120/135 … │  右の上：見出し「ステータス」
│                         │ ├────┬────┬────┬──────────┤
│                         │ │← 左│↑前進│右 →│ ↓ おりる  │  右の下：ボタンを場所いっぱいに広げる
│                         │ │    ├────┤    ├──────────┤  （左右は 2 段ぶん、1 つ 48px 以上）
│                         │ │    │↓後退│    │ ≡ メニュー │
└─────────────────────────┘ └──────────────────────────┘
```

- 上の段は、疑似3D を地図の手前まで広げる（地図の幅のほかは疑似3D）。画面に収まらないときは縮める。下の段は 2 カラム（各 半分の幅）で、左にメッセージ欄、右にステータスとボタン（2026-10-30 のオーナーの感想。GUI-0001 §7.3）。
- ボタンは右下の場所いっぱいに広げ、メッセージ欄と下の端をそろえる（最小 48 × 48px）。
- 1280 × 800 で画面の高さ 725px（メニューを開いたとき 793px）。
- 地図は縮めない（1 マス 16px、仕様書 §11.5）。地図のウィンドウの幅 = 160 + 余白。移動ボタンは残りの幅を 3 等分（1 つ 48px 以上）。

## 2. 要素

| 要素 | 内容・振る舞い | ストーリー |
| --- | --- | --- |
| 階と向き | 「{階}F　{向き}」（例：「3F　北」）。座標は出さない | US-0014 |
| 疑似3D | 仕様書 §11.5 の枠の座標・線。壁にぶつかったら段 0 の正面の壁が 200ms 点滅。説明文を `aria-label` に | US-0014 |
| ステータス | 1 行（HP の警告・体力わずかの枠つき） | — |
| メッセージ欄 | 「ダンジョンに ふみこんだ」「かべだ」、足元の案内（「足元に くだり階段がある」など）。遭遇するとメッセージ欄が消えてから「〇〇が あらわれた！」 | US-0013、US-0014、US-0016、US-0018 |
| 自動地図 | 踏破済みのマスだけ塗り、壁の線・↓↑入・現在地の ▲▶▼◀。座標なし | US-0015 |
| 移動ボタン | 「↑ 前進」「← 左」「右 →」「↓ 後退」（`aria-label`：前進・左を向く・右を向く・後退）。左右は 2 段ぶんの高さ。タップで 1 回動く | US-0014 |
| 矢印キー | ページのどこでも効く。操作できないとき（応答待ち・逐次表示中・メニュー表示中）は捨てる | US-0014 |
| 階段・帰還のボタン | 足元に応じて「↓ おりる」「↑ のぼる」「宿屋へ戻る」のどれか 1 つ。ないときも左の列（8.5em）の幅を空け、メニューボタンの位置を変えない | US-0016、US-0017 |
| メニューボタン | 「≡ メニュー」。右端。押すと GameMenu（GUI-0003 §2）を、地図と移動ボタン・操作の行の場所に出す | US-0021 |

## 3. メニューを開いたとき

```
│ 3F　北 / 疑似3D / メッセージ欄 / ステータス（そのまま）│
│ ┌─【 メニュー 】──────────────────┐ │  地図・移動ボタン・操作の行の代わりに出す
│ │  もどる                         │ │
│ │ ▶ヒール                         │ │
│ │  そうび / もちもの / ステータス / おと │
│ └─────────────────────────────────┘ │
```

- 開いている間は、移動・階段のボタンと矢印キーは使えない（仕様書 §11.4）ので、隠してよい。
- 広い画面では、右下のボタン（移動・階段・メニュー）の場所に出す。地図は右上に残す。
- メニューの方が高いので、疑似3D がさらに縮む（iPhone 11 の Safari で 202px。最小は 200px）。それでも収まらない分は縦にスクロールする（375 × 667 で 46px。GUI-0001 §7.2）。

## 4. 指で隠れないか

- 移動ボタンは画面の右の下の方、メニューボタンは右端の操作の行。上から詰めて並べる（GUI-0001 §2-1）ので、背の高い画面（414 × 814 など）では、その下に空きが出る。右手の親指で押すとき、指は画面の下の方にあり、疑似3D・メッセージ欄・ステータス（上半分）を隠さない。
- 左手で操作する人は、左右の移動ボタンを押すとき地図に指がかかる（地図は見えにくくなるが、操作はできる）。試作で確かめる。
