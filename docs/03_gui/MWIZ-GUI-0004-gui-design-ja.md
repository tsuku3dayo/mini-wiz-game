# GUI-0004 ダンジョン画面（`#/dungeon`）

## 1. 画面の形

### 1.1 414 × 715（iPhone 11 の Safari）

```
┌────────────────────────────────────┐
│ 3F　北                              │  LocationLabel（h2 18px）。画面名「ダンジョン」は見た目で隠す
│      ╲                    ┌──┐     │
│       ┃╲──────────────╱┃  │  │     │  疑似3D（SVG、4:3）
│       ┃ ┃            ┃ ┃  │  │     │  幅 = min(320, 画面の幅, 高さに収まる幅)
│       ┃ ┃ ↓ くだり階段 ┃ ┃  │  │     │  → 414 × 715 で 269 × 202
│       ┃╱──────────────╲┃  └──┘     │
│      ╱                              │
│ ┌────────────────────────────────┐ │
│ │（メッセージ欄 5 行）             │ │
│ └────────────────────────────────┘ │  間は 8px だけ（GUI-0001 §2-1）
│ ┌─【 ステータス 】────────────────┐ │
│ │ゆうしゃ Lv 12 HP120/135 MP 31/ 43│ │  ステータス（1 行・見出し付き。GUI-0001 §4.4）。メッセージ欄の下（戦闘と同じ）

│ │          │ │   │ │↓後退│ │   │   │  高さは地図に合わせる（ボタン 1 つ 80px 以上）
│ └──────────┘ └───┘ └────┘ └───┘   │
```

### 1.2 大きさの計算

| 画面（CSS px） | 疑似3D | 縦のはみ出し（試作で測った値） |
| --- | --- | --- |
| 414 × 715（iPhone 11 の Safari） | 269 × 202 | 0 |
| 414 × 814（iPhone 11 のホーム画面のアプリ） | 320 × 240 | 0 |
| 375 × 667（下限） | 224 × 168 | 0 |
| 412 × 839（Pixel 7） | 320 × 240 | 0 |
| 1280 × 800（PC） | 320 × 240 | 0 |

- 試作で測った値（2026-10-30。メッセージ欄 5 行）。メッセージ欄が 1 行ふえたので、狭い画面では疑似3D が 4 行のときより小さい（414 × 715 で 317 → 288）。ステータスに見出しを付けたので、さらに小さい（288 → 269。GUI-0001 §7.4）。
- 疑似3D の幅 = min(320, 使える幅, 画面に収まる高さ × 4/3)。最小 幅 173px（高さ 130px。それより狭くなるときは縦にスクロールする）。

### 1.3 広い画面（600px 以上。PC）

```
ダンジョン
3F　北
┌──────────────────────────────────────┐
│                                      │
│   疑似3D（地図の手前まで広げる。      │ ┌──────────┐
│          1280 × 800 で 580 × 435）    │ │ 自動地図  │  地図は右。縦の中心を疑似3D の中心にそろえる
│                                      │ │ 176×176  │  最小 176px。疑似3D が縮むと大きくなる
└──────────────────────────────────────┘ └──────────┘
┌─────────────────────────┐ ┌─【 ステータス 】──────────┐
│（メッセージ欄 6 行）     │ │ゆうしゃ Lv 12 HP120/135 … │  右の上：見出し「ステータス」
│                         │ ├────┬────┬────┬──────────┤
│                         │ │← 左│↑前進│右 →│ ↓ おりる  │  右の下：ボタンを場所いっぱいに広げる
│                         │ │    ├────┤    ├──────────┤  （左右は 2 段ぶん、1 つ 48px 以上）
│                         │ │    │↓後退│    │ ≡ メニュー │
└─────────────────────────┘ └──────────────────────────┘
```

- 上の段は、疑似3D と地図で幅を分け合う（2026-10-30 のオーナーの感想。GUI-0001 §7.3）。
  1. 疑似3D の幅 = 上の段の幅 − 地図の最小（176px＋枠）− 間 8px。画面に収まらないときは、高さに合わせて縮める。
  2. 地図の一辺 = (min(疑似3D の右に残った幅, 上の段の高さ) − 枠) × 0.9。最小 176px（元の 160px の 1.1 倍）。一回り小さく、という感想（4 回目）で、200px・10 割から改めた。
  3. 地図は右に寄せ、縦の中心を疑似3D の縦の中心にそろえる（5 回目の感想で、下寄せから少し上げた。2026-10-30）。
- 下の段は 2 カラム（各 半分の幅）で、左にメッセージ欄（6 行）、右にステータスとボタン。ボタンは右下の場所いっぱいに広げ、メッセージ欄と下の端をそろえる（最小 48 × 48px）。
- 1280 × 800 で画面の高さ 713px（メニューを開いたとき 781px）。1366 × 657 では疑似3D が 505px に縮み、地図が 225px に大きくなる（GUI-0001 §7.3）。
- 地図は縮めない（1 マス 16px、仕様書 §11.5）。地図のウィンドウの幅 = 160 + 余白。移動ボタンは残りの幅を 3 等分（1 つ 48px 以上）。

## 2. 要素

| 要素 | 内容・振る舞い | ストーリー |
| --- | --- | --- |
| 階と向き | 「{階}F　{向き}」（例：「3F　北」）。座標は出さない | US-0014 |
| 疑似3D | 仕様書 §11.5 の枠の座標・線。壁にぶつかったら段 0 の正面の壁が 200ms 点滅。説明文を `aria-label` に。閉じた扉は壁の線の中に扉の形（正面：3 辺と取っ手、左右：3 本の線）、残っている宝箱は「□ たからばこ」の文字（v1.1。仕様書 v1.25） | US-0014、US-0040 |
| ステータス | 1 行（HP の警告・体力わずかの枠つき） | — |
| メッセージ欄 | 「ダンジョンに ふみこんだ」「かべだ」、足元の案内（「足元に くだり階段がある」など）。遭遇するとメッセージ欄が消えてから「〇〇が あらわれた！」。扉・宝箱の行（「とびらが しまっている」「とびらを あけた！」「たからばこを みつけた！」「たからばこから 〜を てにいれた！」など。v1.1） | US-0013、US-0014、US-0016、US-0018、US-0040 |
| 自動地図 | 踏破済みのマスだけ塗り、壁の線・↓↑入・現在地の ▲▶▼◀。座標なし。閉じた扉の辺は info 色の太い線（扉の中身は描かない。v1.1） | US-0015、US-0040 |
| 移動ボタン | 「↑ 前進」「← 左」「右 →」「↓ 後退」（`aria-label`：前進・左を向く・右を向く・後退）。左右は 2 段ぶんの高さ。タップで 1 回動く | US-0014 |
| 矢印キー | ページのどこでも効く。操作できないとき（応答待ち・逐次表示中・メニュー表示中）は捨てる | US-0014 |
| 階段・帰還のボタン | 足元に応じて「↓ おりる」「↑ のぼる」「宿屋へ戻る」のどれか 1 つ。正面が扉なら「扉をあける」、宝箱なら「宝箱をあける」を、足元より先に同じ場所に出す（v1.1。仕様書 v1.25。オーナーの依頼「「宿屋へ戻る」の場所に」）。ないときも左の列（8.5em）の幅を空け、メニューボタンの位置を変えない。「宝箱をあける」（6 文字）も 1 行で収まることを 04 で測る | US-0016、US-0017、US-0040 |
| メニューボタン | 「≡ メニュー」。右端。押すと GameMenu（GUI-0003 §2）を、地図と移動ボタン・操作の行の場所に出す | US-0021 |

## 3. メニューを開いたとき

```
│ 3F　北 / 疑似3D / メッセージ欄 / ステータス（そのまま）│
│ ┌─【 メニュー 】──────────────────┐ │  地図・移動ボタン・操作の行の代わりに出す
│ │  もどる                         │ │
│ │ ▶ヒール                         │ │
│ │  そうび / もちもの / ステータス / おと │
│ └─────────────────────────────────┘ │
```

- 開いている間は、移動・階段のボタンと矢印キーは使えない（仕様書 §11.4）ので、隠してよい。
- 広い画面では、右下のボタン（移動・階段・メニュー）の場所に出す。地図は右上に残す。
- メニューの方が高いので、疑似3D がさらに縮む（iPhone 11 の Safari で 184px。最小は 173px）。それでも収まらない分は縦にスクロールする（375 × 667 で 40px。GUI-0001 §7.4）。

## 4. 指で隠れないか

- 移動ボタンは画面の右の下の方、メニューボタンは右端の操作の行。上から詰めて並べる（GUI-0001 §2-1）ので、背の高い画面（414 × 814 など）では、その下に空きが出る。右手の親指で押すとき、指は画面の下の方にあり、疑似3D・メッセージ欄・ステータス（上半分）を隠さない。
- 左手で操作する人は、左右の移動ボタンを押すとき地図に指がかかる（地図は見えにくくなるが、操作はできる）。試作で確かめる。

## 5. 扉と宝箱（v1.1。仕様書 v1.25）

行き止まりの入口の扉の前で、扉を向いたとき（狭い画面）：

```
│ 3F　北                                  │
│ ┌────────────────────────────────────┐ │
│ │ ＼                              ／ │ │  疑似3D：正面の壁の中に扉の形
│ │   ┌──────────────────────────┐   │ │  （3 辺と取っ手。下の辺は床の線と重なる）
│ │   │      ┌──────────┐        │   │ │
│ │   │      │          │        │   │ │
│ │   │      │        ─ │        │   │ │
│ │   └──────┴──────────┴────────┘   │ │
│ │ ／                              ＼ │ │
│ └────────────────────────────────────┘ │
│ （メッセージ欄）とびらが しまっている     │
│ （ステータス）                          │
│ ［自動地図］［← 左］［↑ 前進 / ↓ 後退］［右 →］ │  地図：閉じた扉の辺は info 色の太い線
│ [扉をあける]                [≡ メニュー]│  「宿屋へ戻る」の場所
└────────────────────────────────────────┘
```

- 宝箱の扉を開けたあと：疑似3D の正面が開き、1 マス先の床の高さに「□ たからばこ」の文字。メッセージ欄に「とびらを あけた！」「たからばこを みつけた！」。左下のボタンが「宝箱をあける」になる。
- 宝箱を開けたあと：「たからばこを あけた！」「たからばこから 〜［R］（〜 +n）を てにいれた！」（行の色はレアリティの色。UR・LG は点滅）。効果音はレアリティごと（EP-0007）。ボタンは消え、奥のマスに入れる。
- 敵・ボスの扉：開けるとメッセージ欄が消え、「とびらを あけた！」「〇〇が あらわれた！」から戦闘画面へ（ふつうの遭遇と同じ）。
- 広い画面では、右下のボタンの上の段（階段・帰還ボタンの場所）に「扉をあける」「宝箱をあける」を出す。
- 扉の形の線の太さ・色は壁と同じ（primary、2px）。扉が点滅するのは、扉にぶつかったときの外枠（壁の矩形）だけ。
