# GUI-0002 タイトル画面・名前入力

## 1. タイトル（`#/`）

### 1.1 画面の形（414 × 715）

```
┌────────────────────────────────────┐
│ ↕ 32（安全領域と大きい方）         │
│        ─────── ✦ ───────           │  飾り線（乾いた血、幅 60%、aria-hidden）
│              W I Z                 │  h1 36px（600px 以上は 48px）、くすんだ金
│         ～ 死霊術師の迷宮 ～        │  秘術の紫
│        ─────── ✦ ───────           │
│  ▶つづきから     ゆうしゃ Lv12      │  CommandMenu「タイトル」（幅いっぱい、最大 360px）
│   はじめから                        │  ※ 並びは はじめから／つづきから／おと
│   おと：オフ                        │
│ [インストール]               v1.0  │  インストールのボタン（左）・版（右、古びた灰）
│ ↕ 32                               │
└────────────────────────────────────┘
```

- 縦の中央に寄せる（上下の余白が同じ）。
- 図はカーソルの位置を示すため「つづきから」に ▶ を描いた。項目の並びは仕様書 §11.5 のとおり はじめから → つづきから → おと。
- **メッセージ欄は置かない**（2026-10-30 のオーナーの感想。GUI-0001 §6-12）。

### 1.2 要素

| 要素 | 内容・振る舞い | ストーリー |
| --- | --- | --- |
| メニュー | はじめから（名前入力へ）／つづきから（セーブがあれば右に 16px 空けて「{名前} Lv{n}」、なければ灰色で、選んでも何も出さない）／おと：オフ（選ぶと「おと：オン」に変わり、確認音が鳴る）。初めのカーソルはセーブがあれば つづきから | US-0006、US-0032 |
| エラー | 続けられないエラーのときは、メニューの下に ErrorPanel（GUI-0007 §4） | US-0012 |
| インストール | ボタン「インストール」。押すと案内のダイアログ（GUI-0007 §3）。インストール済みなら出さない（版の表記は右に残る） | US-0002 |
| 版 | 「v1.0」（`package.json` の version の先頭 2 つ） | US-0006 |

- 更新の帯は画面の上端に出る（GUI-0007 §2）。

## 2. 名前入力（`#/new`）

### 2.1 画面の形（414 × 715、ソフトウェアキーボードを出したとき）

```
┌────────────────────────────────────┐
│ なまえ                              │  画面名 h1 24px
│ ┌────────────────────────────────┐ │
│ │ なまえを いれてください         │ │
│ │ なまえ                          │ │  ラベル（13px、古びた灰）
│ │ ┌────────────────────────────┐ │ │
│ │ │ ゆうしゃ                    │ │ │  入力欄（高さ 48、文字 16px）
│ │ └────────────────────────────┘ │ │
│ │ （エラーの文）            4/8   │ │
│ │  もどる                         │ │
│ │ ▶決定                           │ │
│ └────────────────────────────────┘ │
│ ┌────────────────────────────────┐ │
│ │（メッセージ欄 5 行）            │ │
│ └────────────────────────────────┘ │
├──────────── ソフトウェアキーボード ─┤
└────────────────────────────────────┘
```

- 入力欄と「決定」を画面の上の方に置き、ソフトウェアキーボードで隠れないようにする（下端寄せにしない）。
- 入力欄の文字は 16px 以上（iPhone の Safari が入力時に画面を拡大しないため）。`enterkeyhint="done"`、`autocomplete="off"`。

### 2.2 要素

| 要素 | 内容・振る舞い | ストーリー |
| --- | --- | --- |
| 入力欄 | ラベル「なまえ」、最大 8 文字、右下に「{文字数}/8」。表示した時点でフォーカス | US-0007 |
| エラーの文 | 空・9 文字以上・記号を含む名前で、規則の文（「名前を入力してください」「名前は1〜8文字で入力してください」「つかえない もじが ふくまれています」）。空のときは出さない | US-0007 |
| メニュー | もどる（タイトルへ）／決定（初めのカーソル。規則に合わないときは無効で、理由をメッセージ欄に出す） | US-0007 |
| キー | Enter：IME 変換中でなければ決定。Esc：もどる | US-0007 |

- 作成すると「{名前}の ぼうけんが はじまった」と出て、宿屋に移る（GUI-0003）。
