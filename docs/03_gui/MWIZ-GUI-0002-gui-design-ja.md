# GUI-0002 タイトル画面・名前入力・クレジット

## 1. タイトル（`#/`）

### 1.1 画面の形（414 × 715）

```
┌────────────────────────────────────┐
│ ↕ 32（安全領域と大きい方）         │  画面の高さが 680 以下なら 16（v1.3）
│ ┌────────────────────────────────┐ │  タイトル画像（<h1> の中の <img>。alt「WIZミニ ～死霊術師の迷宮～」）
│ │           WIZミニ              │ │  横幅いっぱい 398 × 高さ 265（3：2）。広い画面は最大 450 × 300
│ │       ～死霊術師の迷宮～       │ │  読めないときは文字の「WIZミニ」（h1 36px／600px 以上は 48px、
│ │      （迷宮の通路の絵）        │ │  くすんだ金）と副題（秘術の紫）
│ └────────────────────────────────┘ │
│  ▶つづきから     ゆうしゃ Lv12      │  CommandMenu「タイトル」（幅いっぱい、最大 360px）
│   はじめから                        │  ※ 並びは はじめから／つづきから／おと／クレジット
│   おと：オフ                        │
│   クレジット                        │  v1.2 で追加（選ぶとクレジット画面へ）
│ [インストール]               v1.0  │  インストールのボタン（左）・版（右、古びた灰）
│ ↕ 32（高さ 680 以下なら 16）       │
└────────────────────────────────────┘
```

- 縦の中央に寄せる（上下の余白が同じ）。
- 図はカーソルの位置を示すため「つづきから」に ▶ を描いた。項目の並びは仕様書 §11.5 のとおり はじめから → つづきから → おと → クレジット。
- **メッセージ欄は置かない**（2026-10-30 のオーナーの感想。GUI-0001 §6-12）。
- v1.1（2026-11-05）：飾り線・「WIZ」・副題を、オーナーが用意したタイトル画像に替えた（仕様書 v1.3 §11.5・§13.6）。画像の高さは、エラーの枠（約 118）が出ても、375 × 667・414 × 715・1366 × 657 で縦に収まるように決めた（測った値は `docs/requests/2026-11-05-spec-1.3-title-image.md` §2.3）。
- v1.2（2026-11-10）：メニューの「おと」の下に「クレジット」を足した（オーナーの決定。仕様書 v1.12）。4 行になっても、エラーの枠が出たときに縦に収まる見込みと書いたが、実装して測ると 375 × 667 で 22・1366 × 657 で 9 はみ出した（v1.3 で直した）。
- v1.3（2026-11-10）：画面の高さが 680 以下のとき、上下の余白を 32 → 16 にした（オーナーが選んだ案 A。仕様書 v1.13 §11.3）。タイトル画像・メニューの大きさは変えない。エラーの枠が出ても 375 × 667・414 × 715・1366 × 657 で縦に収まることを測って確かめた（`docs/requests/2026-11-10-spec-1.13-title-padding.md`）。

### 1.2 要素

| 要素 | 内容・振る舞い | ストーリー |
| --- | --- | --- |
| タイトル画像 | 横幅いっぱい・最大 450 × 300（3：2）、中央。`width`・`height` を書いて場所を先に確保する。読めないときは文字の「WIZミニ」と副題に替える | US-0006 |
| メニュー | はじめから（名前入力へ）／つづきから（セーブがあれば右に 16px 空けて「{名前} Lv{n}」、なければ灰色で、選んでも何も出さない）／おと：オフ（選ぶと「おと：オン」に変わり、確認音が鳴る）／クレジット（クレジット画面へ。§3）。初めのカーソルはセーブがあれば つづきから | US-0006、US-0032、US-0039 |
| エラー | 続けられないエラーのときは、メニューの下に ErrorPanel（GUI-0007 §4） | US-0012 |
| インストール | ボタン「インストール」。押すと案内のダイアログ（GUI-0007 §3）。インストール済みなら出さない（版の表記は右に残る） | US-0002 |
| 版 | 「v1.0」（`package.json` の version の先頭 2 つ） | US-0006 |

- 更新の帯は画面の上端に出る（GUI-0007 §2）。

## 2. 名前入力（`#/new`）

### 2.1 画面の形（414 × 715、ソフトウェアキーボードを出したとき）

```
┌────────────────────────────────────┐
│ なまえ                              │  画面名 h1 24px
│ ┌────────────────────────────────┐ │
│ │ なまえを いれてください         │ │
│ │ なまえ                          │ │  ラベル（13px、古びた灰）
│ │ ┌────────────────────────────┐ │ │
│ │ │ ゆうしゃ                    │ │ │  入力欄（高さ 48、文字 16px）
│ │ └────────────────────────────┘ │ │
│ │ （エラーの文）            4/8   │ │
│ │  もどる                         │ │
│ │ ▶決定                           │ │
│ └────────────────────────────────┘ │
│ ┌────────────────────────────────┐ │
│ │（メッセージ欄 5 行）            │ │
│ └────────────────────────────────┘ │
├──────────── ソフトウェアキーボード ─┤
└────────────────────────────────────┘
```

- 入力欄と「決定」を画面の上の方に置き、ソフトウェアキーボードで隠れないようにする（下端寄せにしない）。
- 入力欄の文字は 16px 以上（iPhone の Safari が入力時に画面を拡大しないため）。`enterkeyhint="done"`、`autocomplete="off"`。

### 2.2 要素

| 要素 | 内容・振る舞い | ストーリー |
| --- | --- | --- |
| 入力欄 | ラベル「なまえ」、最大 8 文字、右下に「{文字数}/8」。表示した時点でフォーカス | US-0007 |
| エラーの文 | 空・9 文字以上・記号を含む名前で、規則の文（「名前を入力してください」「名前は1〜8文字で入力してください」「つかえない もじが ふくまれています」）。空のときは出さない | US-0007 |
| メニュー | もどる（タイトルへ）／決定（初めのカーソル。規則に合わないときは無効で、理由をメッセージ欄に出す） | US-0007 |
| キー | Enter：IME 変換中でなければ決定。Esc：もどる | US-0007 |

- 作成すると「{名前}の ぼうけんが はじまった」と出て、宿屋に移る（GUI-0003）。

## 3. クレジット（`#/credits`。v1.2 で追加）

オーナーが用意した例の画像（`docs/requests/credits/credits-example.png`、iPhone の画面）の並び方を、ゲームの色と文字で作る。

### 3.1 画面の形（414 × 715）

```
┌────────────────────────────────────┐
│ ↕ 32（安全領域と大きい方）         │
│ [← もどる]     クレジット          │  戻るボタン（左、48 以上）・見出し h1（24px、くすんだ金、画面の横の中央）
│ ↕ 32                               │
│             PRODUCER               │  役割：13px・古びた灰・字間 0.1em
│          つくだ よしはる           │  名前：20px・太字・羊皮紙の色
│ ↕ 24                               │
│             DIRECTOR               │
│          つくだ よしはる           │
│                                    │
│           GAME DESIGNER            │
│          つくだ よしはる           │
│                                    │
│         GRAPHIC DESIGNER           │
│            CLAUDE CODE             │
│                                    │
│           SOUND CREATOR            │
│            CLAUDE CODE             │
│                                    │
│            PROGRAMMER              │
│            CLAUDE CODE             │
└────────────────────────────────────┘
```

- 上から並べる（縦の中央に寄せない。例の画像と同じ）。幅はタイトル画面と同じ（最大 800px）。
- 背景はほかの画面と同じ夜の黒（例の画像の紺は使わない）。メッセージ欄は置かない。更新の帯は出さない。
- 高さは 600 くらいの見込みで、375 × 667 にも収まる。

### 3.2 要素

| 要素 | 内容・振る舞い | ストーリー |
| --- | --- | --- |
| 戻るボタン | 「← もどる」（`.wiz-button`。「←」は読み上げない）。押す・Enter・Space、または Esc（どこにフォーカスがあっても）でタイトルへ。開いたときのフォーカスはここ | US-0039 |
| 見出し | `<h1>`「クレジット」 | US-0039 |
| 一覧 | `<dl>`。PRODUCER／DIRECTOR／GAME DESIGNER：つくだ よしはる、GRAPHIC DESIGNER／SOUND CREATOR／PROGRAMMER：CLAUDE CODE（仕様書 §11.5 の表のとおり） | US-0039 |

- BGM はタイトルの曲のまま（止まらず、頭に戻らない）。効果音は鳴らさない。
