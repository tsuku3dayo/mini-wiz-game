# GUI-0005 戦闘画面・ゲームクリア画面

## 1. 戦闘（`#/battle`）

### 1.1 画面の形（414 × 715）

```
┌────────────────────────────────────┐
│ ┌────────────────────────────────┐ │
│ │        ┌──────────┐            │ │  敵のウィンドウ（見出しなし）
│ │        │ 敵の絵    │            │ │  128×128 の絵を、どの画面でも 2 倍（256px）
│ │        │ 256×256  │            │ │
│ │        └──────────┘            │ │
│ │          スライム               │ │  敵の名前 24px（ボスは血の赤）。HP は出さない
│ └────────────────────────────────┘ │
│ ┌────────────────────────────────┐ │
│ │ スライムが あらわれた！         │ │  メッセージ欄（5 行分で固定。GUI-0001 §4.2）
│ │                                │ │
│ │                                │ │
│ │                                │ │
│ │                                │ │
│ └────────────────────────────────┘ │
│ ┌────────────────────────────────┐ │
│ │ゆうしゃ Lv 12 HP120/135 MP 31/ 43│ │  ステータス（1 行）。ダメージで HP の値が 200ms 点滅
│ └────────────────────────────────┘ │
│ ┌─【 コマンド 】──────────────────┐ │
│ │▶たたかう                         │ │  CommandMenu「戦闘」
│ │ ヒール                           │ │
│ │ にげる                           │ │
│ └─────────────────────────────────┘ │
│        ↕（あいた高さ）              │
└────────────────────────────────────┘
```

- 上から 敵 → メッセージ欄 → ステータス → コマンド。間を空けずに詰める（2026-10-30 のオーナーの感想。GUI-0001 §6-13）。
- 画面名「戦闘」は狭い画面では見た目で隠す（GUI-0001 §2-5）。
- 広い画面（600px 以上。PC）は、敵の下を左右に分ける（2026-10-30 のオーナーの感想。GUI-0001 §2-6・§7.3）：

```
┌──────────────────────────────────────────────────┐
│                 敵の絵（256px）                    │  敵のウィンドウ（幅いっぱい）
│                   スライム                         │
└──────────────────────────────────────────────────┘
┌────────────────────────┐ ┌───────────────────────┐
│ スライムが あらわれた！ │ ├─【 ステータス 】───────┤  右の上：ステータス（見出し付き）
│（メッセージ欄 6 行）    │ │ゆうしゃ Lv 12 HP120/… │
│                        │ ├─【 コマンド 】─────────┤
│                        │ │▶たたかう              │  右の下：コマンド（1 行 25.6px。GUI-0001 §4.1）
│                        │ │ ヒール / にげる       │
└────────────────────────┘ └───────────────────────┘
```

  1280 × 800 で画面の高さ 581px。
- 敵の絵は、スマートフォンでも 2 倍（256px）で出す（2026-10-30 のオーナーの決定。128px ではスライムが小さく見えるため）。256px は、375 × 667 の幅でも敵のウィンドウに収まる。
- 敵の絵と名前の間は 4px（iPhone 11 の Safari で 1 画面に収めるため。GUI-0001 §7.1）。
- 画面の高さ（試作で測った値、2026-10-30。メニューの行 44px）：狭い画面で 709px（iPhone 11 の Safari の 715 に収まる。375 × 667 では 42px スクロールする）、PC で 772px。

### 1.2 要素

| 要素 | 内容・振る舞い | ストーリー |
| --- | --- | --- |
| 敵の絵 | `enemies/{種類}.png`（128×128。変更の依頼 `docs/requests/2026-10-27-enemy-images-128.md`）、ドットをぼかさない（`image-rendering: pixelated`）、alt は敵の名前。読めなければ絵を消して名前だけ | US-0033 |
| 敵の名前 | 「スライム」など。ボスは「暗黒のネクロマンサー」を血の赤で | US-0018 |
| コマンド | たたかう／ヒール（MP < 3 で無効、理由「MP が たりない」）／にげる（ボス戦で無効、理由「にげられない！」） | US-0019、US-0020、US-0021 |
| メッセージ欄 | 仕様書 §5.8 の戦闘のメッセージ。勝利・死亡・クリアのメッセージを読み終えるまで、戦闘画面と直前の敵を出し続ける（死亡は danger の行で宿屋へ） | US-0019、US-0022、US-0023 |
| ステータス | HP の警告（橙・「！」）、体力わずかの赤い枠（GUI-0007 §1） | US-0019 |

## 2. ゲームクリア（`#/clear`）

```
┌────────────────────────────────────┐
│                                    │
│   暗黒のネクロマンサーを たおした    │  h1（36px、600px 以上は 48px）、くすんだ金。幅が足りなければ折り返す
│ ┌────────────────────────────────┐ │
│ │ 暗黒のネクロマンサーは ほろび、  │ │
│ │ ダンジョンに 平和が もどった     │ │
│ │ ゆうしゃ Lv15                    │ │
│ │ ぼうけんの きろくを セーブした   │ │  回復の緑（autoSaved のとき）
│ │ 2 周目へ すすむ                  │ │  秘術の紫
│ └────────────────────────────────┘ │
│ ┌────────────────────────────────┐ │
│ │ ダンジョンに 平和が もどった     │ │  メッセージ欄（5 行）
│ └────────────────────────────────┘ │
│ ┌────────────────────────────────┐ │
│ │▶宿屋へ                           │ │  CommandMenu「ゲームクリア」
│ └────────────────────────────────┘ │
└────────────────────────────────────┘
```

- 縦の中央に寄せる（タイトル画面と同じ外枠）。
- 見出しは、`clear` の演出のあいだ浮かび上がる（GUI-0007 §1）。
- 「宿屋へ」で次の周へ（「{名前}は 宿屋に もどった」）（US-0024、US-0025）。
