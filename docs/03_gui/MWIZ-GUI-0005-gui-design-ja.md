# GUI-0005 戦闘画面・ゲームクリア画面

## 1. 戦闘（`#/battle`）

### 1.1 画面の形（414 × 715）

```
┌────────────────────────────────────┐
│ ┌────────────────────────────────┐ │
│ │        ┌──────────┐            │ │  敵のウィンドウ（見出しなし。中の背景は真っ黒 #000000。v1.7）
│ │        │ 敵の絵    │            │ │  256×256 の絵を、どの画面でもそのまま（256px）
│ │        │ 256×256  │            │ │
│ │        └──────────┘            │ │
│ │          スライム               │ │  敵の名前 24px（ボスは血の赤）。HP は出さない
│ └────────────────────────────────┘ │
│ ┌────────────────────────────────┐ │
│ │ スライムが あらわれた！         │ │  メッセージ欄（5 行分で固定。GUI-0001 §4.2）
│ │                                │ │
│ │                                │ │
│ │                                │ │
│ │                                │ │
│ └────────────────────────────────┘ │
│ ┌─【 ステータス 】────────────────┐ │
│ │ゆうしゃ Lv 12 HP120/135 MP 31/ 43│ │  ステータス（1 行・見出し付き）。ダメージで HP の値が 200ms 点滅
│ └────────────────────────────────┘ │
│ ┌────────────────┐┌───────┐┌───────┐ │  枠なしの横 1 列のボタン（v1.5）。幅 2：1：1、間 8px
│ │                ││       ││       │ │  高さ 88px。左右の端はほかのウィンドウの外枠にそろえる
│ │    たたかう    ││ヒール ││にげる │ │  選んでいるボタンは枠と文字を淡い金
│ │                ││       ││       │ │  （▶ は出さない）。押せないボタンは灰色
│ └────────────────┘└───────┘└───────┘ │
│        ↕（あいた高さ）              │
└────────────────────────────────────┘
```

- 上から 敵 → メッセージ欄 → ステータス → コマンドのボタン。間を空けずに詰める（2026-10-30 のオーナーの感想。GUI-0001 §6-13）。
- 画面名「戦闘」は狭い画面では見た目で隠す（GUI-0001 §2-5）。
- 広い画面（600px 以上。PC）は、敵の下を左右に分ける（2026-10-30 のオーナーの感想。GUI-0001 §2-6・§7.3）：

```
┌──────────────────────────────────────────────────┐
│                 敵の絵（256px）                    │  敵のウィンドウ（幅いっぱい）
│                   スライム                         │
└──────────────────────────────────────────────────┘
┌────────────────────────┐ ┌─【 ステータス 】───────┐
│ スライムが あらわれた！ │ │ゆうしゃ Lv 12 HP120/… │  右の上：ステータス（見出し付き）
│（メッセージ欄 7 行）    │ └───────────────────────┘
│                        │ ┌──────────┐┌────┐┌────┐  右の下：枠なしの横 1 列のボタン（v1.6）
│                        │ │ たたかう  ││ヒー││にげ│  幅 2：1：1、間 8px。高さは右の列の
│                        │ │          ││ ル ││ る │  残りいっぱい（88 以上）
└────────────────────────┘ └──────────┘└────┘└────┘  ボタンの下の端はメッセージ欄とそろう
```

  1280 × 800 で画面の高さ 581px（v1.6 でも同じ。仮に作って測った）。
- 敵の絵は、スマートフォンでも 256px で出す（2026-10-30 のオーナーの決定。128px ではスライムが小さく見えるため）。v1.1 では、オーナーが用意した 256×256 の絵を拡大せずに出していた（はじめは 128×128 の絵を 2 倍にしていた）。v1.2 で、オーナーが用意した 128×128 の v2 の絵に替え、ぼかさずに 2 倍にして出す（変更の依頼 `docs/requests/2026-11-06-spec-1.4-images-v2.md`。枠の大きさと画面の形は変わらない）。v1.3 で、同じ絵柄の 256×256 の v2 の絵に替え、v1.1 と同じく拡大せずに出す（変更の依頼 `docs/requests/2026-11-06-spec-1.5-enemy-images-256.md`）。256px は、375 × 667 の幅でも敵のウィンドウに収まる。
- v1.7（2026-11-12）：敵の絵を v5（オーナーが用意した 256×256。背景は真っ黒のまま）に替えた（変更の依頼 `docs/requests/2026-11-12-spec-1.19-enemy-images-v5.md`）。画面の背景（`#0b0a0f`）の上では絵のまわりに少し濃い四角が見えるので、オーナーが選んだ案で、**敵のウィンドウの中の背景を真っ黒（`#000000`）にする**。二重線・敵の名前の色は変えない。ほかのウィンドウは `#0b0a0f` のまま。仮に作って撮った（6 体、375 × 667・1280 × 800、体力わずかの赤い枠のとき）：四角は見えず、画面の高さは変わらない（狭い画面 634px・1280 × 800 で 581px）。
- 敵の絵と名前の間は 0px、敵の名前の行の高さは 1.1（iPhone 11 の Safari で 1 画面に収めるため。GUI-0001 §7.1・§7.4）。
- 画面の高さ（試作で測った値、2026-10-30。メニューの行 44px、ステータスに見出し）：狭い画面で 714px（iPhone 11 の Safari の 715 に収まる。375 × 667 では 47px スクロールする）。
- v1.4（2026-11-11）：狭い画面のコマンドを、縦の 3 行（44 × 3）から横 1 列のボタン（高さ 56）に替えた（オーナーの依頼。仕様書 v1.14）。親指で押しやすく、画面の高さも低くなる見込み（実装のあとに測る）。広い画面は縦の 3 行のまま。
- v1.5（2026-11-11）：狭い画面のコマンドを囲むウィンドウ（見出し「コマンド」）をなくし、ボタンの高さを 56 から 88 にした（WS-0019 の実機の確認のあとのオーナーの依頼。仕様書 v1.16）。画面の高さは、枠と見出しの分が減ってボタンが 32 高くなるので、v1.4 の 638px とほぼ同じ見込み（実装のあとに測る）。
- 画面の高さ（TASK-0036 の実装のあとに測った値、2026-11-11）：狭い画面で 638px（v1.3 までの 714px から 76px 低くなった）。414 × 715・375 × 667 とも 1 画面に収まり、ボタンの下端から画面の下端まで 95px・47px。
- v1.6（2026-11-12）：広い画面のコマンドも、狭い画面と同じ枠なしの横 1 列のボタンにした（「コマンド」のウィンドウと縦の 3 行をなくした。オーナーの依頼。仕様書 v1.17）。置き場所は右の列のステータスの下（オーナーが、2 列の下に幅いっぱいに置く案と見比べて選んだ）。ボタンの高さは、88 のままだと下の端がメッセージ欄とそろわず約 40px あくので、右の列の残りいっぱいに伸ばす（いちばん低くて 88）。
- 広い画面の大きさ（v1.6 の依頼で仮に作って測った値、2026-11-12。Chromium）：

| 画面の大きさ | 画面の高さ | ボタンの高さ | ボタンの幅（たたかう／ヒール・にげる） |
| --- | --- | --- | --- |
| 1280 × 800・1024 × 768・800 × 600 | 581px（v1.5 と同じ） | 130px | 186px／93px |
| 600 × 800 | 581px（v1.5 は 598px） | 104px | 136px／68px |

  どれも文字は 1 行に収まり、縦にはみ出さない。狭い画面（414 × 715・375 × 667）は v1.5 と同じ（638px、ボタン 88px）。
- 遭遇の入力止め（v1.6。仕様書 v1.17 §11.8）：遭遇してから、通常の敵は 510ms（遭遇の音の長さ）、ボスは 2906ms（ボス出現の演出の長さ）、ボタンは押せない色（灰色）で、押しても何も起きない。メッセージ欄のタップ・Enter・Space のスキップも効かない。通常の敵では、戦闘画面に移ってから約 0.5 秒ボタンが灰色で、そのあと押せる色になる。音のオン／オフ・動きを減らす設定によらず同じ。

### 1.2 要素

| 要素 | 内容・振る舞い | ストーリー |
| --- | --- | --- |
| 敵の絵 | `enemies/{種類}.png`（256×256 をそのまま 256px で。v1.7 から v5 の絵で、背景は真っ黒。敵のウィンドウの中も真っ黒にする。変更の依頼 `docs/requests/2026-10-30-spec-1.2-screen-design.md`・`docs/requests/2026-11-06-spec-1.5-enemy-images-256.md`）、ぼかさない（`image-rendering: pixelated`）、alt は敵の名前。読めなければ絵を消して名前だけ | US-0033 |

| メッセージ欄 | 仕様書 §5.8 の戦闘のメッセージ。勝利・死亡・クリアのメッセージを読み終えるまで、戦闘画面と直前の敵を出し続ける（死亡は danger の行で宿屋へ） | US-0019、US-0022、US-0023 |
| ステータス | HP の警告（橙・「！」）、体力わずかの赤い枠（GUI-0007 §1） | US-0019 |

## 2. ゲームクリア（`#/clear`）

```
┌────────────────────────────────────┐
│                                    │
│   暗黒のネクロマンサーを たおした    │  h1（36px、600px 以上は 48px）、くすんだ金。幅が足りなければ折り返す
│ ┌────────────────────────────────┐ │
│ │ 暗黒のネクロマンサーは ほろび、  │ │
│ │ ダンジョンに 平和が もどった     │ │
│ │ ゆうしゃ Lv12                    │ │  撃破の前のレベルのまま（上がるのは宿屋の やすむ。v1.4）
│ │ ぼうけんの きろくを セーブした   │ │  回復の緑（autoSaved のとき）。自動セーブしなかったときは
│ │                                  │ │  古びた灰で「スロットが いっぱいなので セーブしなかった」（v1.4）
│ │ 2 周目へ すすむ                  │ │  秘術の紫
│ └────────────────────────────────┘ │
│ ┌────────────────────────────────┐ │
│ │ ダンジョンに 平和が もどった     │ │  メッセージ欄（5 行）
│ └────────────────────────────────┘ │
│ ┌────────────────────────────────┐ │
│ │▶宿屋へ                           │ │  CommandMenu「ゲームクリア」
│ └────────────────────────────────┘ │
└────────────────────────────────────┘
```

- 縦の中央に寄せる（タイトル画面と同じ外枠）。
- 見出しは、`clear` の演出のあいだ浮かび上がる（GUI-0007 §1）。
- 「宿屋へ」で次の周へ（「{名前}は 宿屋に もどった」）（US-0024、US-0025）。
