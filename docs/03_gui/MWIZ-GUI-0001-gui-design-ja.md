# GUI-0001 画面設計 共通

各画面は GUI-0002〜0007。値は仕様書 §11 を基本にし、**スマートフォンの縦画面での表示を最優先** する（ADR-0012）。仕様書 §11 と違う決め方をしたところは §6 にまとめる（承認の後、変更の依頼で仕様書を v1.2 に上げる）。

試作：`prototype/index.html`（公開 URL の `prototype/`）。画面の大きさ・配置と主な操作だけで、ゲームのロジック・保存・音はない。右端の「試作の画面」から各画面を開ける。

## 1. 基準の画面の大きさ

| 端末（CSS px） | 使える高さ | 位置づけ |
| --- | --- | --- |
| iPhone 11 の Safari（414 × 約 715。ツールバーあり） | 715 | **基準**。オーナーの実機（2026-10-26 の回答） |
| iPhone 11 のホーム画面のアプリ（414 × 896、上 48・下 34 の安全領域） | 814 | 基準 |
| 375 × 667（iPhone SE 相当、E2E の `small`） | 667 | **下限**。横にはみ出さない。縦は少しのスクロールを許す（§5） |
| Pixel 7（412 × 839、E2E の `pixel7`） | 839 | Android の代わり（Android の実機はない） |
| 1280 × 800（PC、E2E の `desktop`） | 800 | 広い画面。崩れないこと |

## 2. 配置の決まり（狭い画面 = 幅 600px 未満）

1. **上から詰めて並べる。** ウィンドウの間は 8px（見出しのあるウィンドウは見出しの分を足す）だけにし、操作を下端に寄せない。あいた高さは画面の一番下に出る（2026-10-30 のオーナーの感想。§7）。
2. 並びは、上に情報、その下にメッセージ欄、その下に操作。宿屋はメッセージ欄のすぐ下にコマンドを置く。ダンジョン・戦闘は、メッセージ欄と操作の間に 1 行のステータスを置く（ダンジョン：疑似3D → メッセージ欄 → ステータス → 地図と移動ボタン、GUI-0004。戦闘：敵 → メッセージ欄 → ステータス → コマンド、GUI-0005）。
3. 1 画面に収める。収まらないときは、ダンジョンの疑似3D を高さに合わせて縮め（GUI-0004 §2）、もちものの一覧の高さを縮める（GUI-0006）。
4. 左右の余白は 8px と安全領域の大きい方、上下は 8px と安全領域の大きい方（`env(safe-area-inset-*)`）。
5. ダンジョン・戦闘では、画面名の `<h1>`（「ダンジョン」「戦闘」）を見た目では隠す（読み上げには残す）。ほかの画面は出す。
6. 広い画面（600px 以上）は、最大幅 800px で中央に置き、2 カラムを使う（2026-10-30 のオーナーの感想。§7.3）。
   - 宿屋：上は 左にステータス・右に実績、下は 左にメッセージ欄・右にコマンド（メニュー・確認）（GUI-0003 §1）。ステータス画面は持たない（GUI-0003 §3）。
   - ダンジョン：上は 左に階と向き・疑似3D（地図の手前まで広げる）、右上に地図。下は 左にメッセージ欄、右の上にステータス、右の下に移動ボタンと階段・メニューのボタン（右下の場所いっぱい）（GUI-0004 §1.3）。
   - 戦闘：敵の下を左右に分け、左にメッセージ欄、右の上にステータス、右の下にコマンド（GUI-0005 §1.1）。
   - 装備：2 つのウィンドウを横に並べる。

## 3. デザインの決まり

仕様書 §11.3 のとおり。

- 色：CSS 変数 `--wiz-color-*`（夜の黒 `#0B0A0F` の背景、羊皮紙 `#E8DCC0` の文字と線、くすんだ金 `#C9A227` の見出し、灯火の琥珀 `#FFC845` のカーソル）。レアリティの色も同じ。
- 文字：端末のフォント（ADR-0010）。`--wiz-font`、16px・行の高さ 1.6・字間 0.05em。数字は `tabular-nums`。
- ウィンドウ：二重線（外 2px・間 3px・内 1px）、角丸と影なし。見出しは「【 見出し 】」で線を切る。
- ウィンドウの内側の余白（狭い画面）：上下 8px（見出しがあるときは上 12px）、左右 12px。上下は仕様書 §11.3 のとおり（1 回目の試作は 10px だったが、iPhone 11 の Safari で 1 画面に収めるため仕様書の値に戻した。2026-10-30）。左右は 1 回目の試作から 12px（仕様書は 8px）。
- ボタン：枠 2px、最小 48 × 48px。押している間は琥珀の地に黒の文字。
- フォーカスリング：琥珀 2px・外側 2px。

## 4. 部品

### 4.1 コマンドメニュー（CommandMenu）

仕様書 §11.4 のとおり。1 行の高さ 44px 以上。カーソル「▶」、↑↓ は端で止まる、Enter・Space・タップで決定、選べない項目は理由をメッセージ欄に出す、Esc は `onCancel` のあるメニューだけ。

- 行間を詰めて 25.6px にした試作は、実機で押し間違えたので 44px に戻した（2026-10-30。§6-11、§7.1）。
- **マウスで操作する広い画面（幅 600px 以上かつ `pointer: fine`。PC）では、行間を詰めて 1 行 25.6px（メッセージ欄・ステータスと同じ）にする**（2026-10-30 のオーナーの感想。§6-15、§7.3）。行が詰まるので、この画面ではメニューの行にフォーカスの枠を描かず、カーソルを「▶」と琥珀の文字で示す。指で触る広い画面（タブレット）は 44px のまま。

### 4.2 メッセージ欄（MessageLog）

仕様書 §11.8 のとおり。ただし **高さは 5 行分で固定**（戦闘も同じ。仕様書は 4 行。§6-10）。出す行も最大 5 行。広い画面（PC）のダンジョンは 6 行分、戦闘は 7 行分（2026-10-30 のオーナーの感想。§7.3）。折り返しで枠に入りきらないときは古い行から消し、新しい行をいつも見せる。400ms ごとに 1 行、タップ・Enter で残りを出す、応答が 300ms を超えたら右下に ▼。danger の行があると外側の線が赤。

- タイトル画面には置かない（GUI-0002 §1。§6-12）。装備・もちもの・ステータスの画面にも置かない（どの画面の大きさでも。GUI-0003 §3、GUI-0006。§6-19）。

### 4.3 確認（ConfirmMenu）

見出し「かくにん」、文と はい／いいえ。初めのカーソルは いいえ、Esc は いいえ、Tab で外へ出ない。出す場所は、その画面の操作の場所。

### 4.4 ステータス（StatusPanel）

| 形 | 使う画面 | 中身 |
| --- | --- | --- |
| full | 宿屋・ステータス画面 | 仕様書 §11.6 のとおり（見出しが名前、Lv・EXP・HP・MP・こうげき・ぼうぎょ・すばやさ） |
| 1 行（compact） | ダンジョン・戦闘 | 見出し「ステータス」（2026-10-30 のオーナーの感想。§7.3・§7.4）。行の先頭に名前（くすんだ金）、続けて「Lv 12」「HP120/135」「MP 31/ 43」（3 桁右揃え）。幅が足りなければ折り返す。狭い画面では、見出しの下の余白を上 8px・下 6px に詰める |
| full（広い画面） | 宿屋 | 見出しを「ステータス」にし、名前は 1 行目「なまえ」に置く（くすんだ金）（§7.3） |

- HP の警告（HP ≦ 最大HP × 0.25 で HP を橙・「！」）、体力わずかの赤い枠（HP × 5 ≦ 最大HP）は仕様書のとおり。

### 4.5 ErrorPanel

見出し「エラー」の danger のウィンドウに「きろくを よみかき できません」と「再試行」。メッセージ欄の場所に出す（GUI-0007）。

## 5. 画面遷移

仕様書 §11.2 の遷移図・LocationGuard のとおり。ルートはハッシュ（`#/`・`#/new`・`#/inn`・`#/dungeon`・`#/battle`・`#/clear`・`#/swap`）。そうび・もちもの・ステータスはルートを持たず、宿屋・ダンジョンの中で中身を差し替える。

```
タイトル ─はじめから→ 名前入力 ─決定→ 宿屋 ─ダンジョンへ→ ダンジョン ─遭遇→ 戦闘
   └つづきから→ 宿屋        宿屋・ダンジョン ─メニュー→ そうび／もちもの／ステータス
戦闘 ─勝利→ ダンジョン（満杯なら 入れ替え）  ─死亡→ 宿屋  ─ボス撃破→ クリア ─宿屋へ→ 宿屋
```

## 6. 仕様書 §11 と違う決め方（仕様書 v1.2 で直す）

| 1 | 狭い画面は、広い画面の並びを 1 列に積む（例：宿屋は ステータス → メニュー → メッセージ欄） | 情報 → メッセージ欄 → 操作の順に、上から間を空けずに詰める（§2） | 操作の直前の結果を、操作のすぐ上で読む。下端に寄せるとメッセージ欄と操作の間があく（オーナーの感想） |

- 10・12 は、承認済みの US-0006・US-0010・US-0011・US-0032 の文言にもかかる。15 は ADR-0012（メニューの行は 44px 以上）に「指で触る画面では」と補う。17 は US-0026（ステータス画面）に「広い画面では宿屋に出す」と補う。仕様書 v1.2 で一緒に直し、再承認を受ける。
