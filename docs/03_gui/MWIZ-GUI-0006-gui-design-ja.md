# GUI-0006 装備画面・もちもの画面・入れ替えの画面

並び順・文言・計算は仕様書 §8.6・§8.7 のとおり。ここでは配置を決める。

- 装備画面・もちもの画面（捨てる確認も含む）にはメッセージ欄を置かない（どの画面の大きさでも。2026-10-30 のオーナーの感想。GUI-0001 §7.3・§7.4）。付け替え・捨てた結果は、のうりょくの値と一覧の中身で分かる。入れ替えの画面（§3）はドロップの行を読むので、メッセージ欄を残す。
- PC では一覧の 1 行を 25.6px に詰める（GUI-0001 §4.1）。

## 1. 装備画面（そうび）

```
┌────────────────────────────────────┐
│ そうび                              │
│ ┌─【 そうび 】────────────────────┐ │  枠の一覧（もどる・ぶき・よろい・たて・アクセ）
│ │  もどる                         │ │  各行：部位名（3.5em）＋ 装備名［R］ 補正
│ │ ▶ぶき   バトルアックス［SR］ こうげき +10 │  装備名はレアリティの色。補正は途中で折り返さない
│ │  よろい チェインメイル［N］ ぼうぎょ +5  │
│ │  たて   ―― なし ――              │ │
│ │  アクセ ソロモンのゆびわ［LG］    │ │  幅が足りなければ補正を次の行へ
│ │         こうげき +20 ぼうぎょ +20│ │
│ └─────────────────────────────────┘ │
│ ┌─【 のうりょく 】────────────────┐ │
│ │ こうげき    58 =  28 + 30        │ │  候補にカーソルを合わせると
│ │ ぼうぎょ    55 =  25 + 30        │ │  「 58 →  76 ↑」（緑）／「↓」（橙）
│ │ すばやさ    22 =  22 + 0         │ │
│ │ さいだいHP 135 = 120 + 15        │ │
│ │ さいだいMP  43 =  43 + 0         │ │
│ └─────────────────────────────────┘ │
└────────────────────────────────────┘
```

- 枠を選ぶと、上のウィンドウが候補の一覧（見出しは部位名、「つよい じゅん」、もどる → はずす → 候補）に替わる。初めのカーソルは もどる の次。選ぶとすぐ付け替える（確認なし）。
- 広い画面では 2 つのウィンドウを横に並べる。375 × 667 でも 1 画面に収まる（GUI-0001 §7.4）。
- ストーリー：US-0028。

## 2. もちもの画面

```
┌────────────────────────────────────┐
│ もちもの                            │
│ ┌─【 もちもの 】──────────────────┐ │
│ │ もちもの 23／50                  │ │  50 個で橙と「！」
│ │ [◀]  すべて  [▶]  よわい じゅん  │ │  ◀▶ は 44 × 44 のボタン（Tab では止まらない）
│ │  もどる                         │ │
│ │ ▶［ぶき］ショートソード［R］ こうげき +2 │  「すべて」のときだけ部位を添える
│ │  ［たて］ウッドシールド［N］ ぼうぎょ +1 │
│ │   …（一覧はスクロール）           │ │  高さ：広い画面 8 行（416px）、狭い画面は画面に合わせる
│ └─────────────────────────────────┘ │
└────────────────────────────────────┘
```

- 個体を選ぶと、ウィンドウを確認に替える：「{装備名}［{ランク}］を すてますか？」はい／いいえ。いいえ で一覧に戻り、カーソルを同じ個体に置く。
- 0 個なら「なにも もっていない」と もどる だけ。
- しぼりこみは ←→ キーか ◀▶ のタップで すべて → ぶき → よろい → たて → アクセ と循環する。
- ストーリー：US-0029。

## 3. 入れ替えの画面（`#/swap`）

```
┌────────────────────────────────────┐
│ いれかえ                            │
│ ┌─【 もちものが いっぱいだ 】──────┐ │
│ │ おちている：ミスリルソード［UR］ │ │
│ │             こうげき +28         │ │
│ │ ▶ひろう（すてるものを えらぶ）   │ │
│ │  あきらめる                     │ │
│ └─────────────────────────────────┘ │
│ ┌─────────────────────────────────┐ │
│ │ オークは ミスリルソード［UR］    │ │  ドロップの行（レアリティの色、UR・LG は点滅）
│ │ （こうげき +34）を おとした！    │ │
│ └─────────────────────────────────┘ │
└────────────────────────────────────┘
```

- ひろう → 一覧（もちもの画面と同じ形、よわい じゅん）→ 確認「{捨てる装備}［ランク］を すてて {落ちている装備}［ランク］を ひろいますか？」。あきらめる → 確認「{落ちている装備}［ランク］を あきらめますか？」。
- 2 択では Esc で閉じない。
- ストーリー：US-0030。ドロップの行の色と点滅は US-0027。
