# GUI-0003 宿屋・メニュー・ステータス画面

## 1. 宿屋（`#/inn`）

### 1.1 画面の形（414 × 715）

```
┌────────────────────────────────────┐
│ 宿屋                                │  画面名 h1 24px
│ ┌─【 ゆうしゃ 】──────────────────┐ │
│ │ Lv   12                         │ │  StatusPanel(full)
│ │ EXP 1584（つぎまで 288）         │ │
│ │ HP  120/135 (+15)               │ │
│ │ MP   31/ 43                     │ │
│ │ こうげき  28 (+10)               │ │
│ │ ぼうぎょ  30 (+12)               │ │
│ │ すばやさ  22                     │ │
│ └─────────────────────────────────┘ │
│ ┌─────────────────────────────────┐ │
│ │（メッセージ欄 5 行）              │ │
│ └─────────────────────────────────┘ │  間は 8px だけ（GUI-0001 §2-1）
│ ┌─────────────────────────────────┐ │
│ │▶やすむ                           │ │  CommandMenu「宿屋」
│ │ セーブ                           │ │
│ │ メニュー                         │ │
│ │ ダンジョンへ                     │ │
│ │ タイトルへ戻る                   │ │
│ └─────────────────────────────────┘ │
│        ↕（あいた高さ）              │
└────────────────────────────────────┘
```

広い画面（600px 以上。PC）では、2 段 × 2 カラムにする（2026-10-30 のオーナーの感想。GUI-0001 §7.3）。メニュー（§2）と、タイトルへ戻るの確認（§1.3）も、右下のコマンドの場所に出す。

```
┌─【 ステータス 】──────┐ ┌─【 じっせき 】────────┐
│ なまえ ゆうしゃ        │ │ このキャラクターの きろく│  見出しは「ステータス」。名前は 1 行目（くすんだ金）
│ Lv   12               │ │ そうせんとう 128 回    │  右に実績（狭い画面のステータス画面と同じ中身）
│ EXP 1584（つぎまで 288）│ │ とうばつ     120 体    │
│ …                     │ │ …                     │
└───────────────────────┘ └───────────────────────┘
┌───────────────────────┐ ┌───────────────────────┐
│（メッセージ欄 5 行）   │ │▶やすむ                │  右下にコマンド（1 行 25.6px。GUI-0001 §4.1）
│                       │ │ セーブ / メニュー / …  │
└───────────────────────┘ └───────────────────────┘
```

- 左右のウィンドウは、段ごとに高さをそろえる。1280 × 800 で画面の高さ 468px。

### 1.2 要素

| 要素 | 内容・振る舞い | ストーリー |
| --- | --- | --- |
| メニュー | やすむ（「HP と MP が かいふくした」）／セーブ（「セーブしました」、確認なし）／メニュー（§2）／ダンジョンへ／タイトルへ戻る（§1.3） | US-0008、US-0009 |
| ステータス | full（GUI-0001 §4.4） | US-0008 |

### 1.3 タイトルへ戻るの確認

コマンドの場所を確認に替える：「プレイ中の ぼうけんは きえます。よろしいですか？」はい／いいえ（初め・Esc は いいえ）。はい でタイトルへ、いいえ で元のメニュー（カーソルは「タイトルへ戻る」）。

## 2. メニュー（GameMenu）

宿屋の「メニュー」、ダンジョンの「≡ メニュー」で開く。**操作の場所に替えて** 出す（GUI-0001 §6-6）。狭い画面では、宿屋はコマンドの場所、ダンジョンは地図と移動ボタンの場所。広い画面では、宿屋は右のコマンドの場所、ダンジョンは右下のボタンの場所（GUI-0004 §3）。

```
│ ┌─【 メニュー 】──────────────────┐ │
│ │  もどる                         │ │
│ │ ▶ヒール            （ダンジョンだけ）│
│ │  そうび                         │ │
│ │  もちもの                       │ │
│ │  ステータス                     │ │
│ │  おと：オフ                     │ │
│ └─────────────────────────────────┘ │
```

| 項目 | 振る舞い | ストーリー |
| --- | --- | --- |
| もどる・Esc | 閉じて、フォーカスを開いたもの（宿屋は「メニュー」、ダンジョンは「≡ メニュー」）に戻す | US-0010 |
| ヒール | ダンジョンだけ。MP 不足でも初めのカーソルはここ（無効のときの理由「MP が たりない」）。使っても開いたまま | US-0021 |
| そうび・もちもの | GUI-0006 | — |
| ステータス | §3。狭い画面だけ（広い画面では宿屋に能力と実績を出すので、この項目を置かない） | US-0026 |
| おと | その場で切り替え（閉じない）。「おとを オンにした」／「おとを オフにした」 | US-0032 |

- 初めのカーソルは「もどる」の次。Tab で外へ出ない。

## 3. ステータス画面

**狭い画面だけ**。広い画面（PC）では宿屋に能力と実績を出すので、ステータス画面を持たない（2026-10-30 のオーナーの感想。GUI-0001 §6-17）。ダンジョンからは、宿屋に戻ると見られる。

```
┌────────────────────────────────────┐
│ ステータス                          │
│ ┌─【 ゆうしゃ 】──────────────────┐ │  能力（full と同じ並び）
│ └─────────────────────────────────┘ │
│ ┌─【 じっせき 】──────────────────┐ │
│ │ このキャラクターの きろく        │ │  秘術の紫
│ │ そうせんとう  128 回            │ │
│ │ とうばつ      120 体            │ │
│ │ しぼう          3 回            │ │
│ │ しゅうかい      2 周目          │ │
│ │ ボスとうばつ    1 回            │ │
│ └─────────────────────────────────┘ │
│ ┌─────────────────────────────────┐ │
│ │▶もどる                           │ │
│ └─────────────────────────────────┘ │
│ （メッセージ欄）                     │
└────────────────────────────────────┘
```

- iPhone 11 の Safari では 1 画面に収まり、375 × 667 では 45px ほど縦にスクロールする（GUI-0001 §7.2）。
- もどる・Esc でメニューに戻る（US-0026）。
