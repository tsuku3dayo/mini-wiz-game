# WIZ ～死霊術師の迷宮～

ブラウザで遊ぶ、1 人用のダンジョン探索 RPG です。宿屋を拠点に、5 階層の迷宮を一人称の視点で進み、敵と戦って強くなり、5 階の奥にいる「暗黒のネクロマンサー」を倒すとクリアです。クリアしたあとも、同じキャラクターで何周でも遊べます。

- 遊ぶ：https://tsuku3dayo.github.io/mini-wiz-game/
- 版：1.0.0（画面の表示は「v1.0」）

スマートフォンの縦画面を一番に考えて作っています。PC のブラウザでも遊べます。サーバーは使わず、遊んだ記録はその端末のブラウザの中（端末内保存）にだけ残ります。

## 遊び方

1. タイトルで「はじめから」を選び、名前（1〜8 文字）を決めます。
2. 宿屋では、「やすむ」で HP・MP を回復し、「セーブ」で記録を残せます。「ダンジョンへ」で迷宮に入ります。
3. ダンジョンでは、移動ボタン（PC は矢印キー）で進みます。地図は歩いたマスだけが描かれます。階段で上下の階へ移り、1 階の入口から宿屋に戻れます。
4. 歩いていると敵に出会います。「たたかう」「ヒール」（MP を使って回復）「にげる」から選びます。倒すと経験値が入り、レベルが上がり、装備を落とすことがあります。
5. 拾った装備は「メニュー → そうび」で付け替えられます。持てる数は 50 個までです。
6. 5 階のボスを倒すとクリアです。記録は自動でセーブされ、2 周目へ進みます。

そのほか：

- 音は、はじめは鳴りません。タイトルかゲーム中のメニューの「おと：オフ」を選ぶとオンになります。
- キーボードだけでも遊べます（Tab・矢印キー・Enter・Esc）。読み上げ機能（iPhone の VoiceOver など）にも対応しています。
- ホーム画面に追加すると、アプリのように開けて、通信のない場所でも遊べます（タイトルの「インストール」に手順があります）。

## 動かし方（開発する人向け）

Node.js 24 で動かしています。

| コマンド | すること |
| --- | --- |
| `npm install` | 必要な道具を入れる |
| `npm run dev` | 開発用に、手元でアプリを開く |
| `npm run build` | 公開用のファイルを `dist/` に作る |
| `npm run preview` | 作った `dist/` を手元で開く |
| `npm run verify` | 書き方の検査・文書の検査・単体テスト・組み立て・`dist/` の検査をまとめて行う |
| `npm run test:e2e` | 画面を実際に動かすテスト（Playwright。スマートフォン 2 種類と PC の 3 つの大きさ） |
| `npm run icons` | アイコンの画像を作り直す |

`main` にマージすると、GitHub Actions がテストを動かし、`dist/` を GitHub Pages に公開します。URL に `?debug=1` を付けると、テスト用の入口（`window.__wiz`）ができます。

## ファイル構成

```
mini-wiz-game/
├─ index.html          画面の骨組み
├─ public/             そのまま公開するファイル（起動の見張り boot.js・アイコン・敵の絵）
├─ src/
│  ├─ domain/          ゲームのルール（キャラクター・迷宮・戦闘・装備など）
│  ├─ logic/           表示のための計算（説明文・地図・並び順など）
│  ├─ api/             ゲーム API と端末内保存
│  ├─ ui/              画面と部品・スタイル
│  ├─ audio/           効果音と BGM（Web Audio で合成）
│  └─ platform/        ブラウザの機能のつなぎ（保存・時刻・PWA）
├─ tests/              単体テスト（Vitest）
├─ e2e/                画面のテスト（Playwright）
├─ scripts/            検査とアイコン作りのスクリプト
└─ docs/               仕様書と、開発の成果物（要件・設計・テスト・作業計画・実施記録・ふりかえり）
```

仕様は `docs/specification-ja.md`、開発の進め方は `docs/SDD-PROCESS_v3.md` にあります。

## 権利とクレジット

- 敵の絵（`public/enemies/`）は、オーナー（tsuku3dayo）が用意したものです。
- 効果音と BGM は、音声ファイルを使わず、ブラウザの Web Audio でその場で合成しています。
- 文字は端末に入っているフォントを使い、Web フォントは読み込みません。
- 公開するアプリには、オフラインで動かすための [Workbox](https://github.com/GoogleChrome/workbox)（MIT License）が入っています。
